시작 전에 끝내 두세요

7일은 전부 「만드는 날」로 씁니다. 설치는 여기서 끝냅니다.

맥은 20분, 윈도우는 30분쯤 걸립니다. 나눠서 하셔도 됩니다. 8월 23일(일) 자정까지만 끝내 주시면 됩니다.

  1. 클로드 앱 설치 — 인터넷 주소창에 claude.ai/download. 화면에서 「Download for Windows」(맥은 「Download for macOS」)라고 적힌 단추를 누릅니다.
    주소가 claude.com으로 바뀌어도 정상입니다. 옆에 있는 다른 단추는 누르지 마세요.
  2. (윈도우만) 부품 하나 더 — 주소창에 git-scm.com/install/windows → 파란 글씨 「Click here to download」 → 받은 파일 실행 → «Next»만 계속 누르고 마지막에 «Install» → «Finish».
    영어가 잔뜩 나오는데 하나도 안 읽으셔도 됩니다. 처음 나온 그대로가 제일 좋은 설정입니다. 검은 창이 떠도 정상이니 «X»로 닫으세요. 다 하면 클로드 앱을 껐다 켜 주세요.
  3. 로그인하고 인사 한 번 — 「Google로 계속하기」가 제일 빠릅니다. 그다음 입력칸에 안녕하세요라고 쳐 보세요.
    답이 오면 성공입니다. 이 화면을 찍어 두세요 (인증 사진 1장)
    📝 로그인에 쓰신 이메일 주소를 적어 두세요. 다음 결제를 같은 주소로 하셔야 합니다.
  4. 유료 구독(Pro) 결제 — 주소창에 claude.ai/upgrade
    ① 위쪽 «개인»(Individual) ② «월간»(Monthly) ③ «Pro»라고 적힌 칸의 단추
    «월간»을 꼭 확인하세요. 연간은 1년치를 한 번에 냅니다. 그리고 «Pro»는 이름으로 찾으세요 — 자리가 왼쪽이 아닐 수 있고, 맨 왼쪽 «Free»($0)를 누르면 결제가 안 됩니다.
    카드 뒷면 세 자리(CVC)까지 넣습니다. "해외 결제" 문자가 와도 정상입니다. 끝나면 영수증 메일이 옵니다.
  5. 작업 폴더 만들어 열기 — 바탕화면에 ai-challenge 폴더를 만듭니다. 앱 맨 위 가운데에 Chat · Cowork · Code 세 글자가 있습니다. 맨 오른쪽 «Code» → «Local» → «Select folder» → 그 폴더를 고르고 오른쪽 아래 «폴더 선택»을 누릅니다.
    아래 칸에 한 줄 치고 «엔터»:
    답이 오면 오늘 끝입니다. 이 화면도 찍어 주세요 (인증 사진 2장)
  6. 앱 세 개 깔기 — ①인스타그램 → ②쓰레드 → ③텔레그램 순서로. 쓰레드는 인스타 계정으로 로그인하면 됩니다.
    앱은 셋, 아이디는 둘입니다. 인스타는 비공개로 두셔도 됩니다.

  • "(윈도우) 폴더를 골랐는데 아무 일도 안 일어나요." → 2번을 안 하신 겁니다. 하고 나서 앱을 껐다 켜세요

뭘 만들지 고민하지 않으셔도 됩니다. 아래에서 하나만 고르세요.

① 우리 아이 성장 기록 ② 부모님 약 시간표 ③ 우리 가게 메뉴판
④ 모임 회비 정산표 ⑤ 가족 기념일 디데이 ⑥ 여행 계획표
⑦ 경조사 기록 ⑧ 냉장고 재고표 ⑨ 내 기록장(산·책) ⑩ 반려동물 건강수첩

  2. "고쳐 주세요"를 세 번 해 봅니다 — 색 / 글씨 크기 / 순서
  3. 예시로 채워진 자리에 내 진짜 내용을 넣습니다. 오늘은 세 칸만 채우세요. 나머지는 예시로 두셔도 됩니다
  4. 게시해서 주소를 받고, 내 폰으로 열어 봅니다. 그 링크를 진짜 보내야 할 사람에게 보내세요 — 가족 단톡방·모임방

  3. 도우미로 실제로 쓸 것 3장을 뽑습니다
  4. 그중 하나를 오늘 실제로 씁니다. 진짜 보내거나, 붙이거나, 주세요. 안 맞는 데가 있으면 3번 고치기

한 달을 벌어 둡니다

매일 "오늘 뭐 쓰지"에서 멈추지 않도록, 오늘 30개를 쌓아 둡니다.

다 쓰려고 하지 마세요. 쌓아 두는 날입니다.

  1. 내 말투를 AI에게 가르칩니다 — 예전에 쓴 글·카톡·댓글 5개를 통째로 붙여넣습니다
    쓴 글이 없으시면 하고 싶은 말을 3분 말하고 받아쓰기 하셔서 넣으세요
  2. 글감 30개를 먼저 뽑습니다 (주제를 3~5가지로 갈라서)
  3. 글감을 글 30개로 살 붙입니다
  4. 🔴 내가 직접 써 보고 AI 글과 견줍니다. 오늘의 진짜 수업은 여기입니다

(글 5개를 여기에 붙여넣으세요)
② 글감 30개 먼저
제 말투 규칙을 지키면서, 올릴 글감 30개를 뽑아 주세요.
주제를 4가지로 나누고, 주제마다 글감을 7~8개씩 주세요.

③ 글 30개

제 말투 규칙을 지켜 주시고, 파일로 저장해 주세요.
④ 내가 이기는지 봅니다
여기까지 하신 일이 붙여넣기 세 번뿐이죠. 이제 직접 해 보십니다.
  1. 글감 하나를 고르고, AI가 쓴 글은 잠깐 덮어 둡니다
  2. 타이머 5분. 그 글감으로 직접 손으로 써 보세요. 다섯 줄이면 충분합니다. 맞춤법 틀려도 됩니다
  3. 둘을 나란히 붙여넣고 아래를 물어봅니다
  4. 나온 규칙서로 글 3개를 다시 뽑습니다 — 아까 것과 다를 겁니다
  5. 그중 하나에 내 얘기 한 줄을 넣어 올립니다

카드뉴스 10장을 찍어냅니다

그림 그리는 AI는 안 씁니다. 틀 하나를 만들어 내용만 갈아끼웁니다.

  1. 카드 틀 한 장을 만듭니다 — 이때 한 장에 들어갈 글자 수 상한을 꼭 정하세요. 이게 오늘의 안전장치입니다
  2. 어제 쓴 글 하나를 카드 5장으로 만듭니다
  3. 다른 글로 5장 더 — 틀은 그대로, 내용만 갈아끼웁니다. 이때 "틀 하나면 계속 찍어낼 수 있구나"를 느끼십니다
  4. 그림으로 저장 → 폰으로 옮기기 → 인스타에 한 세트
① 틀 만들기
카드뉴스 틀을 만들어 주세요.
- 정사각형, 휴대폰에서 잘 보이게
- 맨 위에 제목, 가운데에 내용, 맨 아래에 제 이름
- 글씨는 크게. 한 장에 두 줄을 넘지 않게 해 주세요
- 색은 (원하는 색)으로
② 카드 5장
아래 글을 방금 만든 틀에 넣어 5장짜리 카드뉴스로 만들어 주세요.
1장은 제목, 2~4장은 내용, 5장은 마무리로요.
글자가 틀 밖으로 넘치지 않게 줄여 주세요.
