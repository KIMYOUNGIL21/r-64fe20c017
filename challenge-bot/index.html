그밤PD 왕초보 챌린지 1기

오픈채팅 봇 세팅 순서

새로 산 안드로이드 폰에서 그대로 따라 하시면 됩니다.
PC는 필요 없습니다 — 전부 폰 안에서 끝납니다.

0단계 · 5분 생사확인 이게 안 되면 나머지가 다 무의미합니다. 제일 먼저. 1단계 · 방장봇 켜기 카카오 공식 기능. 공짜, 5분, 위험 0. 2단계 · 매크로드로이드 설치 권한 3개가 핵심입니다. 3단계 · Claude API 키 지금 쓰시는 구독과 별개로 충전이 필요합니다. 4단계 · 매크로 만들기 트리거 → 조건 → 3개 동작. 5단계 · 안전장치 이걸 안 걸면 상품이 죽습니다. 막혔을 때 증상별로 어디가 문제인지.

05분 생사확인

A안(매크로드로이드) 전체가 이 한 가지에 달려 있습니다. 카카오톡 오픈채팅 알림에 "답장" 입력칸이 뜨는가. 이게 안 뜨면 매크로드로이드가 답장을 넣을 자리가 없어서 2단계부터는 해도 소용이 없습니다.

왜 먼저 확인하나
매크로드로이드의 "알림에 답장" 기능은 왓츠앱·텔레그램에서 되는 건 확인됐지만, 카카오톡에서 되는지는 공식 확인된 자료가 없습니다. 제가 확인해드릴 수 없는 유일한 부분이라, 5분 테스트로 먼저 판정하고 들어갑니다.

해볼 것

  1. 새 폰에 카카오톡 설치 → 새 계정(또는 부계정)으로 로그인
  2. 챌린지 오픈채팅방에 이 새 계정으로 입장 (아직 아무 말 안 하셔도 됩니다)
  3. 새 폰 설정에서 카카오톡 알림을 켜고, 그 방의 알림도 켜져 있는지 확인
  4. 메인 폰(원래 쓰시던 폰)으로 그 방에 아무 말이나 한마디 보냅니다
  5. 새 폰 화면 위에서 아래로 쓸어내려 알림창을 엽니다
  6. 그 카톡 알림을 손가락으로 아래로 한 번 더 펼쳐 봅니다
✅ 통과 — 알림 안에 "답장" 버튼이나 글자 입력칸이 보인다.
→ 1단계로 가시면 됩니다.
❌ 실패 — 알림에 답장칸이 전혀 없다. 알림을 눌러야 카톡이 열린다.
→ 여기서 멈추고 저에게 알려주세요. A안이 막힌 것이라 다른 방식으로 다시 짜야 합니다. (1단계 방장봇은 이것과 무관하게 되니까, 그건 그대로 켜두시면 됩니다.)

1방장봇 켜기공짜 · 위험 0

카카오가 공식으로 만든 오픈채팅 자동응답 기능입니다. 매크로드로이드가 되든 안 되든 이건 켜두면 무조건 이득이라 먼저 합니다.

어디서 켜나

  1. 방장 계정(사장님 원래 폰)으로 챌린지 오픈채팅방에 들어갑니다
  2. 오른쪽 위 줄 세 개(≡) 메뉴를 누릅니다
  3. 메뉴 안에서 오픈채팅 봇 → 방장봇 활성화를 누릅니다
  4. 설정을 눌러 아래 세 가지를 채웁니다
항목내용
환영 메시지새로 들어온 사람에게 자동으로 뜨는 인사. 방 규칙 + "/" 안내를 넣으세요.
알림 메시지정해둔 시각에 자동 발송. 매일 미션 공지에 쓸 수 있습니다.
질문과 답변최대 10개. 참가자가 입력창에 / 를 치면 목록이 뜨고, 고르면 답이 나옵니다.
한계를 알고 쓰세요
방장봇은 미리 적어둔 10개만 답합니다. 자유롭게 물어본 질문에는 답을 못 합니다. 그래서 방장봇 = 1층(자주 나오는 10개), 매크로드로이드+AI = 2층(나머지 질문) 으로 겹쳐 쓰는 구조입니다.

10개에 뭘 넣나

지금 FAQ 뱅크가 비어 있습니다(개강 전이라 실제 질문이 아직 안 쌓임). 우선 이 정도로 채워두고, 개강 후 진짜 반복되는 질문이 나오면 그걸로 교체하세요.

  • 과제 어디에 올리나요
  • 완주 기준이 뭔가요
  • 클로드 유료 결제 꼭 해야 하나요
  • 오늘 미션이 뭔가요
  • 자료는 어디서 받나요
  • 답변은 몇 시에 해주시나요
  • 하루 빠지면 어떻게 되나요
  • 수요일 화면 보는 시간 언제인가요

2매크로드로이드 설치

0단계를 통과하셨을 때만 진행하세요.

  1. 새 폰에서 Play 스토어 → MacroDroid 검색 → 설치
  2. 앱을 열고 안내를 넘깁니다

권한 3개 — 이게 진짜 핵심입니다

권한왜 필요한가어디서
알림 접근 이게 없으면 카톡 메시지를 아예 못 봅니다 매크로드로이드가 처음 알림 매크로를 만들 때 알아서 물어봅니다. 뜨면 허용
배터리 최적화 제외 이게 제일 자주 사고 납니다. 안 하면 몇 시간 뒤 폰이 앱을 재우고 봇이 조용히 죽습니다 폰 설정 → 배터리 → 앱별 관리 → MacroDroid → 제한 없음 / 최적화 안 함
자동 시작 허용 폰이 재부팅돼도 봇이 다시 켜지게 폰 설정에서 "자동 실행" 또는 "자동 시작" 검색 → MacroDroid 켜기
메뉴 이름은 폰마다 다릅니다
삼성·샤오미·구글 픽셀이 다 다르게 부릅니다. "배터리 최적화", "절전", "백그라운드 제한" 같은 말이 보이면 그게 그겁니다. 뜻은 하나 — 이 앱은 재우지 마라.

3Claude API 키 발급

지금 쓰시는 클로드 구독과 완전히 별개입니다
월 구독료를 내고 계셔도 API는 따로 돈을 충전해야 씁니다. 이걸 모르면 4단계에서 계속 오류만 납니다.
  1. 폰 브라우저에서 console.anthropic.com 접속 → 로그인
  2. Billing(결제) 에서 카드를 등록하고 최소 금액을 충전합니다 (5달러면 한참 씁니다 — 아래 비용 참고)
  3. API Keys 메뉴 → Create Key → 키를 만듭니다
  4. 키가 딱 한 번만 보입니다. 바로 복사해서 폰 메모장에 붙여두세요. 나중에 다시 못 봅니다
키는 비밀번호입니다
이 키가 남에게 넘어가면 사장님 카드로 돈이 나갑니다. 오픈채팅방·카톡·캡처에 절대 올리지 마세요. 실수로 노출되면 콘솔에서 그 키를 삭제(Revoke)하고 새로 만드시면 됩니다.

비용이 얼마나 나오나

쓸 모델은 claude-haiku-4-5 입니다. 빠르고 싸서 FAQ 자동응답에 맞습니다. 공식 요금은 입력 100만 글자토큰당 $1, 출력 $5입니다.

계산 예시(실측 아님 — 아래 가정으로 제가 계산한 값입니다): FAQ 안내문을 매번 2,000토큰쯤 같이 보내고 답이 200토큰이라고 치면, 답변 1건에 약 0.003달러(4원쯤). 하루 100건이면 400원 안팎입니다. 실제 금액은 콘솔 Usage에서 며칠 지켜보시면 정확히 나옵니다.

답변 품질이 아쉬우면 4단계 본문의 모델 이름만 claude-sonnet-5 로 바꾸시면 됩니다(더 똑똑하지만 조금 느리고 비쌉니다).

4매크로 만들기

매크로드로이드에서 매크로 추가(+) 를 누르고 아래 순서대로 채웁니다. 트리거 1개, 조건 2개, 동작 3개입니다.

트리거 (언제 작동하나)

  • 알림 → 알림 수신 을 고릅니다
  • 앱: 카카오톡
  • 내용 필터에 오픈채팅방 이름을 넣습니다 (다른 카톡방까지 봇이 답하면 사고입니다)
  • 메시지 내용은 변수 notification_text 에 담깁니다

조건 (이럴 땐 하지 마라)

무한 루프 방지 — 반드시 넣으세요
봇이 자기가 쓴 답장에 또 반응하면 끝없이 혼자 떠듭니다. 방에서 쫓겨나기 딱 좋습니다.
  • 보낸 사람이 봇 계정 본인이면 중단
  • 메시지가 물음표(?)로 끝나거나 특정 호출어(예: 봇아)로 시작할 때만 작동 — 이걸 권합니다. 방의 모든 잡담에 봇이 끼어들면 방 분위기가 죽습니다

동작 1 — 따옴표 정리

참가자가 " 를 쓰면 아래 요청이 깨집니다. 먼저 지워둡니다.

  • 변수 → 문자열 조작 → notification_text 안의 " 를 ' 로 바꿔 새 변수 q 에 저장
  • 줄바꿈도 같이 공백으로 바꿔두면 더 안전합니다

동작 2 — Claude에 물어보기

연결 → HTTP 요청 을 고르고 이렇게 채웁니다.

칸넣을 값
방식POST
URLhttps://api.anthropic.com/v1/messages
Content Typeapplication/json
헤더 1x-api-key : 3단계에서 받은 키
헤더 2anthropic-version : 2023-06-01
응답 저장변수 resp (이름은 아무거나)

본문(Body) 에는 아래를 그대로 넣고, [여기에 FAQ] 부분만 사장님 안내 내용으로 바꾸세요.

{
  "model": "claude-haiku-4-5",
  "max_tokens": 300,
  "system": "너는 그밤PD 왕초보 챌린지 오픈채팅방의 안내 도우미다. 아래 정보 안에서만 답한다. 규칙: (1) 3문장 안으로 짧게 답한다. (2) 아래 정보에 없는 질문은 지어내지 말고 정확히 '없음' 이 두 글자만 답한다. (3) 힘들다, 막혔다, 포기하고 싶다, 저만 이런가요 같은 감정이 섞인 말에는 절대 답하지 말고 '없음' 이라고만 답한다. 위로나 격려는 네 역할이 아니다. [여기에 FAQ 내용을 적으세요]",
  "messages": [
    { "role": "user", "content": "{lv=q}" }
  ]
}
가운데 "content": "{lv=q}" 가 참가자 질문이 들어가는 자리입니다. 매크로드로이드에서 변수를 넣는 표기법이며, 앱 버전에 따라 [lv=q] 로 쓰기도 합니다. 변수 넣기 버튼으로 고르시면 알아서 맞는 형태로 들어갑니다.

동작 3 — 답을 꺼내서 카톡에 붙이기

돌아오는 응답은 이렇게 생겼습니다.

{
  "content": [ { "type": "text", "text": "여기가 답변입니다" } ],
  "stop_reason": "end_turn"
}
  • 매크로드로이드에 JSON 값 가져오기 기능이 있으면 경로를 content[0].text 로 지정해 변수 answer 에 담습니다
  • 그 기능이 없는 버전이면, 문자열 조작으로 "text":" 다음부터 다음 " 앞까지를 잘라내면 됩니다
  • 마지막으로 알림 → 알림에 답장 동작을 넣고 보낼 내용에 answer 를 넣습니다
테스트는 꼭 빈 방에서
챌린지 방 말고 혼자 만든 테스트 오픈채팅방에서 먼저 돌려보세요. 트리거 필터를 그 방 이름으로 잠깐 바꿔두시면 됩니다. 첫판에 바로 되는 경우는 거의 없습니다.

5안전장치

기술이 아니라 상품을 지키는 부분입니다. 여기가 이 챌린지의 핵심이라 꼭 지켜주세요.

1:1 케어는 봇이 대신하지 않는다
이탈 감지 DM, 자기소개 환영 답글, 완주 축하는 전부 사장님이 직접 하십니다. "제가 옆에서 직접 챙깁니다"가 이 챌린지의 유일한 팔림 포인트입니다. 봇이 대신 말 거는 순간 상품이 죽습니다. 그래서 4단계 본문의 규칙 (3)번에 감정이 섞인 말에는 봇이 입을 다물도록 이미 넣어뒀습니다.
  • 모르면 침묵. 답이 없음 으로 오면 아무것도 보내지 말고 매크로를 끝내세요. 지어낸 답변 한 번이 신뢰를 다 깎습니다
  • 하루 상한. 매크로드로이드 변수로 카운터를 만들어 하루 30~50건 넘으면 멈추게 해두세요. 오류로 폭주할 때 요금을 막아줍니다
  • 방에 공지. "자주 나오는 질문은 자동응답이 먼저 답합니다. 자세한 건 제가 직접 답합니다" 정도로 미리 알려두세요. 몰래 쓰면 들켰을 때 문제가 됩니다
  • 첫 주는 지켜보기. 봇이 뭐라고 답했는지 며칠은 눈으로 확인하세요. 이상하면 바로 끄시면 됩니다
