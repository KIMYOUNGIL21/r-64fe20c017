오픈채팅 봇 세팅 순서

새로 산 안드로이드 폰에서 그대로 따라 하시면 됩니다.
PC는 필요 없습니다 — 전부 폰 안에서 끝납니다.

0단계 · 5분 생사확인 이게 안 되면 나머지가 다 무의미합니다. 제일 먼저. 1단계 · 방장봇 켜기 카카오 공식 기능. 공짜, 5분, 위험 0. 2단계 · 매크로드로이드 설치 권한 3개가 핵심입니다. 3단계 · API 키 3개 준비 재미나이 무료 → 유료 → OpenAI 순으로 흘러갑니다. 4단계 · 매크로 만들기 제일 어렵습니다. 11칸으로 쪼갰고 중간 테스트 2번 있습니다. 5단계 · 안전장치 이걸 안 걸면 상품이 죽습니다. 막혔을 때 증상별로 어디가 문제인지.

05분 생사확인

A안(매크로드로이드) 전체가 이 한 가지에 달려 있습니다. 카카오톡 오픈채팅 알림에 "답장" 입력칸이 뜨는가. 이게 안 뜨면 매크로드로이드가 답장을 넣을 자리가 없어서 2단계부터는 해도 소용이 없습니다.

왜 먼저 확인하나
매크로드로이드의 "알림에 답장" 기능은 왓츠앱·텔레그램에서 되는 건 확인됐지만, 카카오톡에서 되는지는 공식 확인된 자료가 없습니다. 제가 확인해드릴 수 없는 유일한 부분이라, 5분 테스트로 먼저 판정하고 들어갑니다.

해볼 것

  1. 새 폰에 카카오톡 설치 → 새 계정(또는 부계정)으로 로그인
  2. 챌린지 오픈채팅방에 이 새 계정으로 입장 (아직 아무 말 안 하셔도 됩니다)
  3. 새 폰 설정에서 카카오톡 알림을 켜고, 그 방의 알림도 켜져 있는지 확인
  4. 메인 폰(원래 쓰시던 폰)으로 그 방에 아무 말이나 한마디 보냅니다
  5. 새 폰 화면 위에서 아래로 쓸어내려 알림창을 엽니다
  6. 그 카톡 알림을 손가락으로 아래로 한 번 더 펼쳐 봅니다
✅ 통과 — 알림 안에 "답장" 버튼이나 글자 입력칸이 보인다.
→ 1단계로 가시면 됩니다.
❌ 실패 — 알림에 답장칸이 전혀 없다. 알림을 눌러야 카톡이 열린다.
→ 여기서 멈추고 저에게 알려주세요. A안이 막힌 것이라 다른 방식으로 다시 짜야 합니다. (1단계 방장봇은 이것과 무관하게 되니까, 그건 그대로 켜두시면 됩니다.)

1방장봇 켜기공짜 · 위험 0

카카오가 공식으로 만든 오픈채팅 자동응답 기능입니다. 매크로드로이드가 되든 안 되든 이건 켜두면 무조건 이득이라 먼저 합니다.

어디서 켜나

  1. 방장 계정(사장님 원래 폰)으로 챌린지 오픈채팅방에 들어갑니다
  2. 오른쪽 위 줄 세 개(≡) 메뉴를 누릅니다
  3. 메뉴 안에서 오픈채팅 봇 → 방장봇 활성화를 누릅니다
  4. 설정을 눌러 아래 세 가지를 채웁니다
항목내용
환영 메시지새로 들어온 사람에게 자동으로 뜨는 인사. 방 규칙 + "/" 안내를 넣으세요.
알림 메시지정해둔 시각에 자동 발송. 매일 미션 공지에 쓸 수 있습니다.
질문과 답변최대 10개. 참가자가 입력창에 / 를 치면 목록이 뜨고, 고르면 답이 나옵니다.
한계를 알고 쓰세요
방장봇은 미리 적어둔 10개만 답합니다. 자유롭게 물어본 질문에는 답을 못 합니다. 그래서 방장봇 = 1층(자주 나오는 10개), 매크로드로이드+AI = 2층(나머지 질문) 으로 겹쳐 쓰는 구조입니다.

2매크로드로이드 설치

0단계를 통과하셨을 때만 진행하세요.

  1. 새 폰에서 Play 스토어 → MacroDroid 검색 → 설치
  2. 앱을 열고 안내를 넘깁니다

권한 3개 — 이게 진짜 핵심입니다

권한왜 필요한가어디서
알림 접근 이게 없으면 카톡 메시지를 아예 못 봅니다 매크로드로이드가 처음 알림 매크로를 만들 때 알아서 물어봅니다. 뜨면 허용
배터리 최적화 제외 이게 제일 자주 사고 납니다. 안 하면 몇 시간 뒤 폰이 앱을 재우고 봇이 조용히 죽습니다 폰 설정 → 배터리 → 앱별 관리 → MacroDroid → 제한 없음 / 최적화 안 함
자동 시작 허용 폰이 재부팅돼도 봇이 다시 켜지게 폰 설정에서 "자동 실행" 또는 "자동 시작" 검색 → MacroDroid 켜기
메뉴 이름은 폰마다 다릅니다
삼성·샤오미·구글 픽셀이 다 다르게 부릅니다. "배터리 최적화", "절전", "백그라운드 제한" 같은 말이 보이면 그게 그겁니다. 뜻은 하나 — 이 앱은 재우지 마라.

3API 키 3개 준비

한도가 차면 다음 키로 자동으로 흘러가는 구조입니다. 재미나이 무료 → 재미나이 유료 → OpenAI 순서. 평소엔 무료 한 개로 거의 다 처리되고, 질문이 몰리는 날에만 뒤 칸이 열립니다.

순서키언제 쓰이나
1번재미나이 무료키평소 전부. 여기서 끝나는 게 정상입니다
2번재미나이 유료키무료 한도가 찼을 때만
3번OpenAI 키위 둘 다 막혔을 때만. 거의 안 열립니다

① 재미나이 무료키

이미 갖고 계실 수 있습니다. 판매상품(쓰레드·인스타 자동화) 만들 때 쓰던 그 키와 같은 종류입니다. 저장해두신 게 있으면 그대로 쓰시면 됩니다.
  1. 폰 브라우저에서 aistudio.google.com/apikey 접속 → 구글 계정 로그인
  2. API 키 만들기 를 누릅니다
  3. 프로젝트를 고르라고 하면 결제가 연결 안 된 프로젝트를 고릅니다 (그래야 무료 등급)
  4. 나온 키를 복사해서 폰 메모장에 붙여둡니다

② 재미나이 유료키

헷갈리기 쉬운 부분입니다
무료/유료는 키를 두 종류로 만드는 게 아니라, 결제가 연결된 프로젝트에서 만든 키냐 아니냐의 차이입니다. 키 생김새는 똑같습니다.
  1. 같은 aistudio.google.com/apikey 화면에서 API 키 만들기 를 한 번 더 누릅니다
  2. 이번엔 결제(Billing)가 연결된 프로젝트를 고릅니다. 없으면 화면 안내대로 카드를 등록해 프로젝트 하나를 결제 연결하세요
  3. 나온 키를 복사해둡니다. ①번과 헷갈리지 않게 메모에 "유료"라고 적어두세요

③ OpenAI 키

  1. 폰 브라우저에서 platform.openai.com/api-keys 접속 → 로그인
  2. Create new secret key → 키를 만듭니다. sk- 로 시작합니다
  3. 딱 한 번만 보입니다. 바로 복사해서 메모장에 붙여두세요
  4. Billing에서 소액이라도 충전해두세요. 잔액 0이면 3번 칸이 무용지물입니다
키 3개 전부 비밀번호입니다
남에게 넘어가면 사장님 카드로 돈이 나갑니다. 오픈채팅방·카톡·캡처에 절대 올리지 마세요. 실수로 노출되면 각 사이트에서 그 키를 삭제하고 새로 만드시면 됩니다.

제게 알려주실 것

키 값 자체는 보내지 마세요. 아래 세 가지만 알려주시면 됩니다.

  • ①②③ 각각 구했다 / 못 구했다
  • ②번(재미나이 유료)에서 결제 연결된 프로젝트를 만드셨는지
  • ③번 OpenAI에 잔액을 넣으셨는지

키는 사장님 폰 메모장에만 두시고, 4단계에서 그 자리에 직접 붙여넣으시면 됩니다.

4매크로 만들기

여기가 제일 어렵습니다. 그래서 잘게 쪼갰습니다.
한 번에 다 만들지 마세요. 중간에 두 번 멈춰서 테스트하는 지점을 표시해뒀습니다. 거기서 꼭 확인하고 넘어가세요. 한꺼번에 만들면 안 될 때 어디가 틀렸는지 절대 못 찾습니다.

먼저 — 매크로가 뭔가

매크로는 "이럴 때 → 이렇게 해라" 규칙 한 장입니다. 세 부분으로 되어 있습니다.

부분뜻우리 경우
발동조건언제 작동할지카톡 알림이 왔을 때

변수가 뭔가

변수는 이름을 붙인 상자입니다. 값을 담아뒀다가 나중에 꺼내 씁니다. 우리는 상자 세 개를 씁니다.

상자 이름담기는 것
sys봇에게 주는 안내문. 한 번 정하면 안 바뀝니다
q참가자가 방금 한 질문. 매번 바뀝니다
answerAI가 준 답. 매번 바뀝니다

직접 타이핑하지 마세요. 글자 쓰는 칸 옆에 돋보기나 { } 모양 버튼이 있습니다. 그걸 누르면 변수 목록이 뜨고, 거기서 고르면 알아서 정확한 형태로 들어갑니다. 손으로 치면 오타 하나에 안 됩니다.

4-1 · 빈 매크로 만들기

  1. 매크로드로이드 앱을 엽니다
  2. 아래쪽 매크로 추가 또는 오른쪽 아래 ＋ 버튼을 누릅니다
  3. 발동조건 / 동작 / 요건 세 칸이 비어 있는 화면이 나옵니다. 여기를 채워갈 겁니다
  4. 맨 위 이름 칸에 챌린지봇 이라고 적어둡니다
화면 아래 탭 세 개가 이렇게 되어 있습니다
발동조건 = 언제 작동할지 (트리거) · 동작 = 뭘 할지 · 요건 = 폰이 어떤 상태일 때만

메시지 내용을 거르는 건 전부 "발동조건" 안에서 합니다. "요건"은 배터리·시간·와이파이 같은 폰 상태를 따지는 곳이라, 카톡 내용은 거기서 못 거릅니다.

4-2 · 발동조건 — "카톡 알림이 오면"

  1. 발동조건 옆의 ＋ 를 누릅니다
  2. 카테고리 목록에서 알림 을 고릅니다
  3. 알림 수신됨 (또는 "알림이 왔을 때") 을 고릅니다
  4. 애플리케이션 선택 → 목록에서 카카오톡 만 체크합니다
  5. 같은 화면에 아래 칸들이 더 있습니다. 이름은 버전마다 조금 다릅니다
이런 이름의 칸여기에 넣을 것
텍스트 내용 / 내용 포함 / 텍스트 일치 봇아
호출어입니다. 이걸로 시작하는 말에만 봇이 반응합니다
알림 제목 / 제목 포함 오픈채팅방 이름 (정확히)
카톡은 알림 제목에 방 이름이 들어갑니다
제외할 텍스트 / 무시할 내용 비워둬도 됩니다 (호출어가 이미 걸러줍니다)
방 이름 칸을 비워두지 마세요
이걸 안 넣으면 사장님의 모든 카톡(가족·친구·업무)에 봇이 답합니다. 진짜 사고 납니다.

호출어(봇아)도 꼭 넣으세요. 이게 없으면 방의 모든 잡담에 봇이 끼어들고, 봇이 자기 답장에 또 답하는 무한 루프가 생깁니다. 봇은 "봇아"로 시작하는 말을 안 하니까, 호출어 하나로 루프까지 같이 막힙니다.

이 발동조건이 작동하면 매크로드로이드가 메시지 내용을 자동으로 담아둡니다. 그 상자 이름이 notification_text 입니다. 이건 우리가 만드는 게 아니라 원래 있는 겁니다.

칸 이름이 위 표와 다르면 멈추고 캡처를 보내주세요. 이 화면이 버전 차이가 제일 큰 곳입니다. 비슷해 보이는 칸에 찍어 넣으면 나중에 원인 찾기가 훨씬 어려워집니다.

4-3 · 요건 — 지금은 비워둡니다

여기서 하실 일이 없습니다. 그냥 넘어가세요.

요건 옆의 ＋ 를 누르면 기기 상태 · 날짜/시간 · 미디어 · 배터리/전원 같은 목록이 나옵니다. 전부 폰 상태에 관한 것이라 우리가 지금 쓸 게 없습니다.

요건은 4-9와 4-10에서 딱 한 번 씁니다 — "앞 칸에서 답을 못 받았을 때만 다음 칸을 열어라". 그때는 목록에서 변수 를 고르게 됩니다. 목록을 아래로 내리면 있습니다. 지금은 아닙니다.

(3) 힘들다, 막혔다, 포기하고 싶다, 저만 이런가요 같은 감정이 섞인 말에는
    절대 답하지 말고 '없음' 이라고만 답한다. 위로나 격려는 네 역할이 아니다.
[여기에 FAQ 내용을 적으세요]

왜 상자에 따로 담느냐 — 이 안내문을 세 군데(1·2·3번 칸)에 똑같이 써야 합니다. 상자에 담아두면 나중에 FAQ를 고칠 때 여기 한 곳만 고치면 됩니다.

4-5 · 동작 2 — 질문 다듬기 (q 상자)

왜 필요한가
참가자가 큰따옴표(") 를 쓰면 다음 단계에서 보내는 편지 모양이 깨져서 실패합니다. 미리 바꿔둡니다.
  1. 동작 ＋ → 변수 → 변수 설정
  2. 새 변수 q, 종류 문자열
  3. 값 칸에 변수 버튼으로 [notification_text] 를 넣습니다
  4. 같은 화면 안에 바꾸기 / 치환(replace) 옵션이 있으면 " 를 ' 로 바꾸도록 설정합니다
치환 옵션이 안 보이면 일단 넘어가세요.
없으면 q 에 [notification_text] 만 담고 진행하시면 됩니다. 큰따옴표를 쓴 질문만 가끔 실패하는데, 봇이 조용히 넘어가도록 5단계에서 막아둡니다. 나중에 캡처 보내주시면 그때 방법을 찾아드리겠습니다.

4-6 · 동작 3 — 1번 칸 : 재미나이 무료키에 물어보기

여기가 실제로 AI에게 편지를 보내는 부분입니다. 어렵게 들리지만 편지 부치기와 똑같습니다.

편지로 치면여기선
받는 사람 주소URL
봉투에 붙이는 신분증헤더 (= API 키)
편지 내용본문(Body)
돌아온 답장응답
  1. 동작 ＋ → 연결 (또는 "네트워크") → HTTP 요청
  2. 아래 표대로 칸을 채웁니다
칸넣을 값
방식(Method)POST
URLhttps://generativelanguage.googleapis.com/v1beta/models/gemini-flash-latest:generateContent
Content Typeapplication/json
헤더 이름x-goog-api-key
헤더 값①번 무료키를 붙여넣기
응답 저장할 변수resp (새로 만드세요)

본문(Body) 칸에는 아래를 통째로 붙여넣습니다.

{
  "system_instruction": { "parts": [ { "text": "[lv=sys]" } ] },
  "contents": [ { "parts": [ { "text": "[lv=q]" } ] } ],
  "generationConfig": { "maxOutputTokens": 300 }
}
이 모양은 절대 건드리지 마세요
중괄호 { }, 대괄호 [ ], 큰따옴표 ", 쉼표 , 를 하나만 지워도 전부 실패합니다. 붙여넣은 다음 [lv=sys] 와 [lv=q] 두 자리만 변수 버튼으로 다시 골라 넣으세요.
모델 이름은 반드시 gemini-flash-latest
구글이 개별 모델을 수시로 없앱니다. 판매상품 만드실 때 gemini-2.5-flash 가 죽어서 새 구매자가 전원 실패했던 그 사고와 똑같은 함정입니다. -latest 는 구글이 현행 모델로 계속 갱신해주는 별칭이라 잘 안 죽습니다.

4-7 · 동작 4 — 답 꺼내기

답장이 이렇게 생긴 채로 resp 상자에 들어옵니다. 여기서 진짜 답변 글자만 꺼내야 합니다.

{
  "candidates": [
    { "content": { "parts": [ { "text": "여기가 진짜 답변입니다" } ] } }
  ]
}
  1. 동작 ＋ → 변수 → JSON 값 가져오기 (또는 "JSON 파싱")
  2. 가져올 곳: resp
  3. 경로에 이걸 넣습니다 → candidates[0].content.parts[0].text
  4. 담을 변수: answer (새로 만드세요)
"JSON 값 가져오기" 가 안 보이면 — 대신 변수 설정에서 문자열을 잘라내면 됩니다. "text": " 다음부터 그다음 " 앞까지. 이 방법이 필요하면 캡처 보내주세요, 같이 봐드리겠습니다.

4-8 · 동작 5 — 카톡에 답장

  1. 동작 ＋ → 알림 → 알림에 답장
  2. 보낼 내용에 변수 버튼으로 [lv=answer] 를 넣습니다
🛑 여기서 멈추고 테스트하세요 (1차 관문)
지금까지가 봇의 최소 형태입니다. 2번·3번 칸은 아직 없어도 됩니다.

1. 매크로를 저장하고 켜짐(ON) 상태로 둡니다
2. 테스트용 오픈채팅방을 혼자 하나 만듭니다 (챌린지 방에서 하지 마세요)
3. 발동조건의 방 이름 필터를 잠깐 그 테스트 방 이름으로 바꿉니다
4. 다른 폰으로 그 방에 봇아 안녕 이라고 보냅니다
5. 답이 오나 봅니다

답이 오면 → 4-9로. 안 오면 → 6단계 문제 찾기로 가세요. 여기서 안 되는데 2·3번 칸을 붙이면 더 못 찾습니다.

4-9 · 동작 6 — 2번 칸 : 재미나이 유료키 한도 찼을 때만

1번 칸이 막혔을 때만 열리는 예비 칸입니다.

  1. 4-6의 HTTP 요청 동작을 통째로 복제합니다 (동작을 길게 누르면 복제 메뉴가 나옵니다)
  2. 복제본을 열어 헤더 값만 ②번 유료키로 바꿉니다. URL·본문은 절대 손대지 마세요
  3. 4-7의 답 꺼내기 동작도 복제해서 바로 뒤에 붙입니다 (경로 동일)
  4. 이 두 동작에 조건을 씌웁니다 → answer 가 비어 있을 때만 실행
    동작을 길게 눌러 "요건 추가"를 고른 뒤, 목록에서 변수 를 찾으시면 됩니다

4-10 · 동작 7 — 3번 칸 : OpenAI 둘 다 막혔을 때만

거의 안 열리는 칸입니다. 급하지 않으니 나중에 붙이셔도 됩니다.

  1. 동작 ＋ → 연결 → HTTP 요청 을 새로 만듭니다
칸넣을 값
방식POST
URLhttps://api.openai.com/v1/chat/completions
Content Typeapplication/json
헤더 이름Authorization
헤더 값Bearer + ③번 키
Bearer 뒤에 한 칸 띄고 키를 붙입니다. 이 띄어쓰기 빠뜨리는 실수가 제일 흔합니다
응답 저장resp

본문(Body):

{
  "model": "gpt-4o-mini",
  "max_tokens": 300,
  "messages": [
    { "role": "system", "content": "[lv=sys]" },
    { "role": "user",   "content": "[lv=q]" }
  ]
}
답 꺼내는 경로가 재미나이와 다릅니다
OpenAI는 답장 모양이 달라서 경로도 다릅니다 → choices[0].message.content
재미나이 경로를 그대로 쓰면 아무것도 안 나옵니다.

이 두 동작(요청 + 답 꺼내기)에도 조건을 씌웁니다 → answer 가 아직도 비어 있을 때만.

4-11 · 마지막 정리 — 동작 순서 확인

다 만들면 동작 목록이 이 순서여야 합니다. 답장이 맨 마지막입니다.

1. 변수 설정      sys  (안내문)
2. 변수 설정      q    (질문 다듬기)
3. HTTP 요청      재미나이 무료
4. JSON 값 가져오기  → answer
5. HTTP 요청      재미나이 유료   ※조건: answer 비었을 때
6. JSON 값 가져오기  → answer      ※조건: 같음
7. HTTP 요청      OpenAI         ※조건: answer 비었을 때
8. JSON 값 가져오기  → answer      ※조건: 같음
9. 알림에 답장    [lv=answer]     ※조건: answer 가 비어있지도 '없음'도 아닐 때

순서가 다르면 동작을 길게 눌러 위아래로 끌어 옮기시면 됩니다.

🛑 2차 관문 — 최종 테스트
1. 테스트 방에서 다시 봇아 안녕 → 답이 오나
2. FAQ에 없는 걸 물어보기 (예: 봇아 오늘 날씨 어때) → 아무 말도 안 하면 정상
3. 봇아 너무 힘들어요 → 아무 말도 안 하면 정상 (이건 사장님이 직접 답하실 몫)

셋 다 통과하면 발동조건의 방 이름을 진짜 챌린지 방으로 바꾸고 켜시면 됩니다.
메뉴 이름이 안 맞으면 멈추세요
매크로드로이드는 버전마다 메뉴 이름이 조금씩 다릅니다. 제가 적은 이름이 화면에 안 보이면 비슷한 걸 찍지 마시고 그 화면을 캡처해서 보내주세요. 2~3번 헤매실 일을 한 번에 끝낼 수 있습니다.

5안전장치

기술이 아니라 상품을 지키는 부분입니다. 여기가 이 챌린지의 핵심이라 꼭 지켜주세요.

1:1 케어는 봇이 대신하지 않는다
이탈 감지 DM, 자기소개 환영 답글, 완주 축하는 전부 사장님이 직접 하십니다. "제가 옆에서 직접 챙깁니다"가 이 챌린지의 유일한 팔림 포인트입니다. 봇이 대신 말 거는 순간 상품이 죽습니다. 그래서 4단계 본문의 규칙 (3)번에 감정이 섞인 말에는 봇이 입을 다물도록 이미 넣어뒀습니다.
  • 모르면 침묵. 답이 없음 으로 오면 아무것도 보내지 말고 매크로를 끝내세요. 지어낸 답변 한 번이 신뢰를 다 깎습니다
  • 하루 상한. 매크로드로이드 변수로 카운터를 만들어 하루 30~50건 넘으면 멈추게 해두세요. 오류로 폭주할 때 요금을 막아줍니다
  • 방에 공지. "자주 나오는 질문은 자동응답이 먼저 답합니다. 자세한 건 제가 직접 답합니다" 정도로 미리 알려두세요. 몰래 쓰면 들켰을 때 문제가 됩니다
  • 첫 주는 지켜보기. 봇이 뭐라고 답했는지 며칠은 눈으로 확인하세요. 이상하면 바로 끄시면 됩니다
