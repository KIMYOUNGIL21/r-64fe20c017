그밤PD 왕초보 챌린지 1기

조교봇 세팅 순서
(메신저봇R)

안드로이드 공기계에서 그대로 따라 하시면 됩니다.
매크로 11칸 만들기는 폐기 — 이제 파일 하나 붙여넣기로 끝납니다.

예전 안내서(매크로드로이드)와 뭐가 달라졌나
방식을 매크로드로이드에서 메신저봇R로 바꿨습니다. 원리는 같지만(알림 읽고 답장), 메뉴 11칸을 손으로 만드는 대신 완성된 코드 파일을 통째로 붙여넣습니다. 키는 재미나이 무료키 하나면 시작됩니다(나머지 둘은 예비 — 나중에). 권한 3개, 방장봇(1층)은 그대로. 방장봇은 이미 켜져 있으니 이 문서에선 다루지 않습니다.
1단계 · 준비물 확인 공기계 · 부계정 · 키 3개 · 드라이브 폴더 2단계 · 부계정 카톡 준비 방 입장, 알림 켜기, 테스트방 만들기, 답장칸 재확인 3단계 · 메신저봇R 설치 권한 3개가 핵심입니다 4단계 · 봇 코드 붙여넣기 드라이브 → 복사 → 붙여넣기 5단계 · 설정 2칸 채우기 방 이름 + 무료키. 이게 전부입니다 6단계 · 켜고 테스트 점검 → 도움말 → 코치 → 침묵, 4가지 7단계 · 실전 투입 방 공지 한 줄 + 첫 주 관찰 막혔을 때 증상별 원인표 + error.log 읽는 법

1준비물 확인

준비물확인할 것
안드로이드 공기계와이파이 연결, 충전기 꽂아 상시 전원
카톡 부계정공기계에 로그인돼 있을 것. 메인 계정 금지 — 자동응답은 비공식 방식이라 만에 하나 제재돼도 부계정만 다치게
재미나이 무료키 1개폰 메모장에. 이거 하나면 봇이 돌아갑니다. 유료키·OpenAI 키는 예비용이라 나중에(질문이 몰려 무료 한도가 차기 시작하면) 넣어도 됩니다
구글드라이브공기계에 드라이브 앱 + 사장님 구글 계정 로그인. 「조교봇」 폴더에 봇 파일을 올려뒀습니다
API 키는 비밀번호입니다
남에게 넘어가면 사장님 카드로 돈이 나갑니다. 오픈채팅방·카톡·캡처에 절대 올리지 마세요. 노출됐다 싶으면 그 사이트에서 키를 삭제하고 새로 만들면 됩니다.

2부계정 카톡 준비

봇은 카톡 알림을 읽어서 동작합니다. 알림이 안 뜨면 봇은 장님이 됩니다. 이 단계가 사실상 절반입니다.

2-1 · 방 입장과 알림

  1. 공기계 카톡(부계정)으로 챌린지 오픈채팅방에 입장합니다
  2. 그 방을 열고 오른쪽 위 ≡ → 알림이 켜져 있는지 확인합니다
  3. 폰 설정 → 알림 → 카카오톡 → 알림 허용 + 알림에 메시지 내용 표시가 켜져 있어야 합니다 ("내용 숨기기"로 되어 있으면 봇이 글자를 못 읽습니다)
  4. 카톡 앱 설정 → 알림에서 미리보기 표시도 켭니다

2-2 · 테스트방 만들기

봇의 답은 전부 그 방 안에서 공개됩니다 — 참가자들이 "AI가 이 정도가 되는구나"를 직접 보는 것도 챌린지의 일부입니다. 다만 세팅 중의 시행착오까지 보여줄 필요는 없으니, 테스트용 방을 하나 만듭니다.

  1. 사장님 본계정과 공기계 부계정의 1:1 채팅방을 만듭니다
  2. 서로 한마디씩 보내둡니다
  3. 공기계에서 그 1:1 방이 무슨 이름으로 보이는지 봐둡니다 — 보통 사장님 대화명 그대로입니다. 이 이름을 5단계에서 ROOMS에 같이 넣으면, 이 방이 테스트방이 됩니다
  4. 이 1:1 방의 알림도 켜져 있어야 합니다

2-3 · 답장칸 재확인 (새 폰이라 한 번 더)

지난번 기존 폰에서는 통과했지만, 폰이 바뀌면 결과가 다를 수 있어 새 공기계에서 한 번만 다시 봅니다.

  1. 본계정 폰으로 챌린지방에 아무 말이나 보냅니다
  2. 공기계 화면을 위에서 아래로 쓸어내려 알림창을 엽니다
  3. 카톡 알림을 아래로 한 번 더 펼쳐 봅니다
✅ 답장 버튼/입력칸이 보인다 → 3단계로.
❌ 답장칸이 없다 → 멈추고 알려주세요. 폰 기종 문제라 방법을 다시 찾아야 합니다.

3메신저봇R 설치

  1. 공기계 Play 스토어 → 메신저봇R 검색 → 설치
  2. 앱을 열면 알림 접근 권한을 물어봅니다 → 허용

권한 3개 — 이게 진짜 핵심입니다

권한왜어디서
알림 접근없으면 카톡을 아예 못 봅니다앱 첫 실행 때 물어봄. 안 물어봤으면 폰 설정에서 "알림 접근" 검색 → 메신저봇R 켜기
배터리 최적화 제외제일 자주 사고 나는 곳. 안 하면 몇 시간 뒤 폰이 앱을 재우고 봇이 조용히 죽습니다폰 설정 → 배터리 → 앱별 관리 → 메신저봇R → 제한 없음 / 최적화 안 함
자동 시작 허용재부팅돼도 봇이 다시 켜지게폰 설정에서 "자동 실행/자동 시작" 검색 → 메신저봇R 켜기
메뉴 이름은 폰마다 다릅니다. "절전", "백그라운드 제한" 같은 말이 보이면 그게 그겁니다. 뜻은 하나 — 이 앱은 재우지 마라.

추가로, 앱이 저장공간(모든 파일) 접근을 요청하면 허용해 주세요. 봇이 기록(DB·에러로그)을 폰에 남기는 데 필요합니다.

4봇 코드 붙여넣기

  1. 메신저봇R에서 ＋ (새 봇 만들기) → 이름 조교봇
  2. 드라이브 앱 → 「조교봇」 폴더 → bot.txt를 엽니다 (같은 내용의 bot.js도 있는데, 폰에서는 txt가 열고 복사하기 편합니다)
  3. 내용을 전체 선택 → 복사합니다 (길게 눌러 "모두 선택")
  4. 메신저봇R의 조교봇 편집기(연필 아이콘)를 열고, 원래 있던 예시 코드를 다 지운 뒤 붙여넣기
중간에 일부만 복사되면 안 됩니다
파일 끝이 } 한 줄로 끝나는지 확인하세요. 뒷부분이 잘린 채 저장하면 6단계 컴파일에서 오류가 납니다. 그때는 당황하지 말고 다 지우고 처음부터 다시 전체복사→붙여넣기 하면 됩니다.

5설정 2칸 채우기

붙여넣은 코드의 맨 위 CFG 부분에서 딱 2칸만 고치면 됩니다.

칸넣을 것
ROOMS봇이 반응할 방 이름. 방 상단에 보이는 그대로 — 한 글자라도 다르면 무반응입니다. 2-2에서 만든 테스트방 이름도 같이 넣어두세요 (아래 예시)필수
GEMINI_FREE재미나이 무료키필수
GEMINI_PAID재미나이 유료키 — 지금은 비워두세요. 나중에 넣으면 무료 한도가 찼을 때 자동으로 이어받습니다예비
OPENAI_KEYOpenAI 키 — 마찬가지로 나중에예비

예를 들어 이렇게 됩니다 (이름은 실제 값으로):

ROOMS: ["왕초보 챌린지 1기", "그밤PD"],
PREFIX: "!조교야",
GEMINI_FREE: "AIza여기에무료키",
GEMINI_PAID: "",
OPENAI_KEY: "",
따옴표 " " 사이에만 붙여넣으세요
따옴표나 쉼표를 지우면 컴파일이 실패합니다. 글자만 바꾸고 기호는 그대로 둔다 — 이것만 기억하시면 됩니다.
GEMINI_MODEL은 절대 건드리지 마세요
gemini-flash-latest 그대로 둡니다. 개별 버전명(gemini-2.5-flash 등)으로 바꾸면 구글이 그 모델을 없앨 때 봇이 통째로 죽습니다 — 판매상품에서 실제로 겪은 사고입니다.

6켜고 테스트

  1. 편집기에서 저장 → 컴파일 (버튼 이름이 "재컴파일"일 수 있음). 오류 없이 끝나야 합니다
  2. 봇 목록에서 조교봇 스위치 ON

테스트 4가지 — 테스트방(1:1)에서, 사장님 본계정으로 보냅니다

보낼 말정상 반응
!조교야 점검🔧 상태표 — 기억(DB) 정상 · 무료키 연결됨 ✅ · 시세조회 정상이면 합격. 예비키 두 줄이 "없음 (없어도 됩니다)"로 나오는 건 정상입니다

!조교야 너무 힘들어요아무 답도 없어야 정상입니다. 위로는 봇이 아니라 사장님 몫 — 일부러 그렇게 만들었습니다
답은 전부 그 방 안에 공개로 옵니다
브리핑·공지초안·점검 전부, 명령을 친 그 방에서 모두가 봅니다. 참가자들이 봇의 능력을 직접 보는 것도 이 챌린지의 그림이라 일부러 이렇게 되어 있습니다.
넷 다 통과하면 세팅 끝입니다. 안 되는 게 있으면 아래 「막혔을 때」로 — 2~3번 해봐도 안 풀리면 화면 캡처와 함께 알려주세요. 혼자 오래 붙잡고 계실 일이 아닙니다.

7실전 투입

  1. 테스트가 끝났으면 봇은 그대로 두면 됩니다 — ROOMS에 챌린지방이 이미 들어 있으니 개강과 동시에 동작합니다
  2. 방 공지에 이 한 줄을 넣어주세요 (몰래 쓰다 들키는 게 가장 나쁩니다):
    "방 운영을 위해 대화 내용이 요약 목적으로 처리될 수 있습니다. 일정 기간 후 자동 삭제됩니다."
  3. 첫 주는 봇이 뭐라고 답하는지 눈으로 지켜보세요. 이상하면 스위치만 끄면 됩니다
  4. 충전기 꽂은 채 화면 꺼두면 됩니다. PC는 꺼도 봇과 무관합니다
봇이 안 하는 것 (고장이 아닙니다)
힘들다는 말에 침묵 · 참가자에게 먼저 말 걸기 없음 · 운영 정보에 없는 질문엔 침묵 · 특정 참가자를 콕 집어 언급하지 않음. 전부 일부러입니다 — "제가 옆에서 직접 챙긴다"가 이 챌린지의 상품이라, 위로와 개인 케어는 사장님 몫으로 남겨뒀습니다.
