카탈로그 파일 받는 곳

이 주소는 그대로 두시고, 필요할 때마다 다시 들어와 받으시면 됩니다.

1. 업데이트 파일 (보통 이걸 받으세요)

이미 쓰고 계신 분용입니다. 설정하신 비밀번호와 받아둔 사진은 그대로 남습니다.

업데이트 파일 받기
  1. 파일을 받습니다 (다운로드 폴더에 저장됩니다)
  2. 코덱스에 업데이트 파일 왔어 라고 칩니다
  3. 끝나면 다시 올려줘

2. 전체 파일 (처음 설치할 때만)

처음 시작하거나, 폴더가 망가졌을 때만 쓰세요. 설정을 다시 채워야 합니다.

전체 파일 받기
  1. 다운로드 폴더에서 오른쪽 클릭 → 압축 풀기
  2. 위치를 바탕 화면 으로 바꾸고 풀기
  3. 생긴 카탈로그 폴더의 설치하기 더블클릭

막히면 그 화면을 캡처해서 강사님께 보내주세요.
