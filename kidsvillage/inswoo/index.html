0. 이 문서를 한 줄로

매일 아침 64번 클릭해서 사진 받고, 골라서, 128개 올리던 일을
클릭 한 번 + 더블클릭 한 번으로 바꾸고, 사진이 사라지지 않는 비밀번호 카탈로그 페이지에 자동으로 올라가게 합니다.
주문 받고, 입금 확인하고, 키즈빌리지에 발주하는 일은 지금 그대로입니다. 바뀌지 않습니다.

판매자님이 말씀하신 불편 4가지와, 이게 어떻게 되는지

불편했던 것바뀐 뒤
상품마다 사진 다운받고 9~12장 고르기컴퓨터가 다 받습니다. 고를 필요도 없습니다 — 페이지가 20장을 다 보여줍니다
카톡 사진이 2~3주 지나면 만료페이지의 사진은 사라지지 않습니다. 고객이 한 달 뒤에 봐도 그대로
경쟁자가 몰래 들어와 사진·양식을 빼감페이지에 비밀번호가 걸립니다. 방 밖 사람과 검색엔진은 못 봅니다 (방 안에 있는 사람은 못 막습니다 — 솔직히 말씀드립니다)
100개 넘게 올라가서 며칠 뒤엔 스크롤로 못 찾음페이지에 검색·정렬이 있습니다. "레깅스" 치면 바로 나옵니다

1. 용어 — 이것만 알면 됩니다

말뜻
카탈로그 페이지인터넷 주소 하나로 열리는 상품 목록 화면. 사진·이름·가격·색상·사이즈가 있고, 검색이 됩니다. 고객이 폰으로 봅니다
엑셀키즈빌리지가 공식으로 주는 상품 목록 파일. 상품명·가격·색상·사이즈·사진 주소가 다 들어 있습니다. 이 파일 하나가 시작점입니다
더블클릭 파일바탕화면 폴더에 있는 아이콘. 두 번 클릭하면 나머지를 컴퓨터가 알아서 합니다
상품마스터컴퓨터가 만들어 주는 엑셀 표. 여기서 가격을 고치거나 품절 표시를 합니다. 판매자님이 손대는 유일한 표
알림 키트카톡방에 올릴 재료. 대표 사진들 + 복사해서 붙일 공지 글
클라우드플레어페이지를 인터넷에 띄워 주는 회사. 무료. 계정 하나 만들고 나면 다시 볼 일 없습니다
AI (클로드·코덱스)이 도구들을 만든 프로그램. 판매자님이 매일 쓰는 건 아닙니다. 8장에서 설명합니다

2. 전체 그림

키즈빌리지 ──엑셀 1클릭──▶ [더블클릭 한 번] ──▶ 카탈로그 페이지 (자동 갱신, 비밀번호)
                              │
                              └──▶ 알림 키트 (대표컷 + 공지글) ──판매자님이 붙여넣기──▶ 오픈카톡방
                                                                                   │
                                          고객: 링크 → 비밀번호 → 상품 보기 → "주문 문구 복사" → CS채널
                                                                                   │
                                          판매자님: 지금처럼 확인 · 입금 · 키즈빌리지 발주 (변화 없음)

컴퓨터가 하는 일: 엑셀 읽기, 사진 받기, 가격 계산, 페이지 만들기, 인터넷에 올리기.
판매자님이 하는 일: 브랜드 고르기, 엑셀 받기(클릭 1), 더블클릭(1), 카톡에 붙여넣기, 그리고 지금 하시던 주문·발주.

3. 처음 한 번만 하는 준비 (사장님과 함께, 약 1시간)

이건 딱 한 번입니다. 사장님이 옆에서(또는 원격으로) 같이 합니다. 혼자 하실 필요 없습니다.

3-1. 준비물

  • 판매자님 노트북 (윈도우)
  • 키즈빌리지 로그인 되는 상태
  • 이메일 주소 하나 (클라우드플레어 계정용)
  • 카탈로그 비밀번호로 쓸 단어 하나 (예: 방 이름 + 숫자)

3-2. 순서

  1. 폴더 받기 — 사장님이 카탈로그 폴더를 바탕화면에 넣어 드립니다. 안에 더블클릭 파일 3개가 있습니다: 설치하기, 로그인하기, 카탈로그 만들기.
  2. 설치하기 더블클릭 — 검은 창이 뜨고 글자가 올라갑니다. 5~10분. "설치 완료" 나오면 끝. (필요한 프로그램을 컴퓨터가 알아서 받습니다)
  3. 클라우드플레어 계정 만들기 — 사장님이 화면을 같이 보며 안내. 이메일 + 비밀번호 정하고 이메일 인증. 이 계정은 판매자님 것입니다. 비밀번호는 판매자님만 압니다.
  4. 로그인하기 더블클릭 — 인터넷 창이 열리며 "허용하시겠습니까?" → 허용. 이걸로 컴퓨터가 페이지를 올릴 권한을 얻습니다.
  5. 설정.txt 열어서 두 줄 채우기 — 카탈로그 비밀번호, 페이지 이름(예: sodam). 저장.
  6. 첫 배포 — 카탈로그 만들기 한 번 돌려 봅니다(4장 순서대로). 끝나면 주소가 나옵니다. 예: https://sodam.pages.dev
  7. 카톡방 공지 고정 — "카탈로그 주소: … / 비밀번호: …" 를 방 공지에 고정합니다.

⚠️ 3번·4번은 계정 만들기·로그인이라 사장님도, AI도 대신 못 합니다. 판매자님 손으로 하셔야 합니다. 그래서 같이 하는 날을 잡습니다.

4. 매일 하는 일 (평일 아침, 15분 · 그중 손은 3분)

아오스타 26가을 신상 66종을 오늘 처음 올린다고 치고, 처음부터 끝까지 갑니다.

4-1. 키즈빌리지에서 브랜드 고르기 — 지금과 같습니다

사이트 보면서 "오늘은 아오스타" 정합니다. 여기는 판매자님 안목이라 컴퓨터가 안 합니다.

4-2. 엑셀 한 번 받기 — 클릭 1번

키즈빌리지 로그인 상태에서:

  1. 주소창에 kidsvillage.co.kr/shop/download_xls.php 입력 → 상품목록 다운로드 화면 (즐겨찾기에 넣어 두세요)
  2. 화면 오른쪽 "STEP 01. 브랜드별 상품 다운로드"
  3. 초성 탭에서 "아" → 아오스타(835) 클릭 (숫자는 그 브랜드의 전체 상품 수)
  4. 아래 "다운로드 — 네이버 스토어팜용" 클릭
  5. 파일이 다운로드 폴더에 떨어집니다. 이름은 네이버_상품현황_브랜드_아오스타…xlsx

이 클릭 한 번이, 예전에 64번 클릭해서 압축파일 받던 일을 통째로 대신합니다.
이 엑셀 안에 사진 주소까지 들어 있어서 컴퓨터가 알아서 받습니다.

4-3. 카탈로그 만들기 더블클릭 — 1번

바탕화면 카탈로그 폴더 → 카탈로그 만들기 더블클릭. 검은 창이 뜹니다.

컴퓨터가 두 가지만 묻습니다:

묻는 것답
"이 엑셀 맞나요? 네이버_상품현황_브랜드_아오스타…"방금 받은 파일이면 엔터
"언제 이후 등록된 상품만 올릴까요? [기본: 30일 전]"신상만 올리려면 날짜 입력. 예: 2026-08-01 → 8월 등록 66종만. 그냥 엔터면 최근 30일

그다음은 자동입니다. 창에 진행이 흘러갑니다:

엑셀 835행 → 대상 66종
[1/66] 에브리레깅스 — 이미지 20장
[2/66] 엔젤프릴티 — 이미지 20장
…  (약 10분. 커피 한 잔)
✅ 상품마스터 66종 · 이미지 1,306장
✅ 페이지 올라감: https://sodam.pages.dev/아오스타
✅ 알림 키트: 알림키트\2026-08-25_아오스타\  (폴더가 자동으로 열립니다)

가격은 이 규칙으로 자동 계산됩니다 (판매자님이 알려주신 규칙 그대로):

도매가(공급가)붙이는 마진예
2만원 미만+2,5007,000 → 9,500
2만원 이상+3,00020,000 → 23,000
3.5만원 이상+3,50035,000 → 38,500

4-4. (필요할 때만) 가격 고치기 · 품절 표시

"너무 싸거나 비싼 건 수기로" 하시던 것 — 상품마스터.xlsx에서 합니다.

  1. 카탈로그 폴더 → 수집 → 아오스타 → 상품마스터.xlsx 열기
  2. 고칠 상품 줄에서 판매가_수정 칸에 원하는 가격 입력 (비워 두면 규칙 가격)
  3. 품절이면 상태 칸을 품절로. 아예 안 보이게 하려면 숨김
  4. 저장 → 카탈로그 만들기 다시 더블클릭 → 이번엔 30초 (사진은 이미 있어서 다시 안 받음)

4-5. 카톡방에 올리기 — 판매자님 손으로

자동으로 열린 알림키트 폴더에:

  • 대표컷 폴더: 상품마다 첫 사진 66장
  • 공지문.txt: 복사해서 붙일 글
  1. 공지문.txt 열어 전체 복사
  2. 오픈카톡방에 붙여넣기
  3. 대표컷에서 마음에 드는 사진 몇 장 첨부 (예전처럼 128개가 아니라 몇 장)
  4. 전송

카톡 전송은 일부러 자동으로 안 합니다. 자동 발송은 카카오 규정 위반으로 계정이 정지될 수 있고, 판매자님 카톡 계정은 고객 명단 그 자체라 잃으면 안 됩니다.

4-6. 주문·입금·발주 — 지금 그대로

CS채널로 주문 받고, 통장 확인하고, 키즈빌리지에 고객 주소 넣어 위탁배송 발주. 여기는 아무것도 안 바뀝니다.

5. 고객은 뭘 보나

  1. 카톡 공지의 링크 누름
  2. 비밀번호 한 번 입력 (폰이 기억해서 다음부턴 안 물음)
  3. 상품 목록 — 검색창에 "티" 치면 티만, "낮은 가격순" 정렬도 됨. NEW 표시, 품절 표시
  4. 상품 누르면 사진 20장 + 가격·색상·사이즈·배송비 3,500원
  5. "주문 문구 복사" 버튼 → [주문] 에브리레깅스 / 색상: ( ) / 사이즈: ( ) / 수량: 1 — 9,500원 이 복사됨
  6. CS채널에 붙여넣고 괄호만 채워 보냄

고객이 상품명·가격을 손으로 안 치니 오타·착각이 줄어듭니다.

지금 미리보기(사진 3장짜리 축소판): 사장님이 보내 드린 링크. 실제 페이지는 사진 20장 전부 실립니다.

6. 뭔가 잘못됐을 때

원칙: 컴퓨터가 틀린 값을 내느니 멈추게 만들었습니다. 빨간 글씨로 멈추면 그날은 예전 방식으로 장사하시고, 사장님께 캡처를 보내 주세요. 장사가 서지 않게 만든 구조입니다.

화면에 이런 게 나오면뜻하실 일
⛔ 엑셀 형식이 바뀌었다키즈빌리지가 엑셀 모양을 바꿈사장님께 캡처. 오늘은 예전 방식
⛔ 이미지가 안 열린다사진 주소가 만료됐거나 정책 변경엑셀을 다시 받아서 한 번 더. 그래도 안 되면 사장님께
"브랜드를 선택해주세요" (키즈빌리지 화면)브랜드 안 누르고 다운로드 누름브랜드 먼저 클릭
대상 0종날짜를 너무 최근으로 넣음날짜를 앞당겨 다시
페이지가 예전 상품 그대로배포가 안 됨(인터넷 끊김 등)인터넷 확인 후 다시 더블클릭
고객이 "비밀번호 틀렸대요"공지의 비밀번호와 설정.txt가 다름둘을 맞춤

절대 하지 마실 것

  • 다른 사람이 만든 .bat나 프로그램을 받아서 카탈로그 폴더에 넣기
  • 설정.txt의 비밀번호를 카톡방 밖 사람에게 주기
  • 상품마스터에 고객 이름·주소 적기 (이 표는 상품 전용입니다. 고객 정보는 지금처럼 따로)

7. 꼭 지켜야 할 것 (약관에서 나온 것)

사장님이 키즈빌리지 이용약관을 직접 읽고 뽑은 것입니다.

  1. 이미지는 판매 용도로만. 키즈빌리지 사진은 도매처 것입니다. 카탈로그는 "방 회원에게 보여주는 정리본"이라 비밀번호를 겁니다. 공개 SNS에 올리지 않습니다.
  2. 최저가 1.6배 정책 — 판매자님이 이미 정확히 알고 계신 그 정책입니다. 페이지에 가격이 적히므로, 방 밖으로 새지 않게 비밀번호를 유지합니다.
  3. 키즈빌리지에 부담 주지 않기 — 컴퓨터는 하루 한 브랜드, 사진 사이사이 쉬면서 받습니다. 여러 브랜드를 한꺼번에 돌리지 마세요.
  4. 카톡 자동 발송 금지 — 위 4-5.
  5. 고객 정보는 페이지에 없음 — 페이지엔 상품만. 주문·주소는 지금처럼 판매자님만.

8. AI 도구 첫걸음 — 클로드와 코덱스

판매자님이 매일 AI를 쓰실 일은 없습니다. 하지만 "이게 뭘로 만들어졌고, 나중에 고치고 싶을 때 누구한테 뭐라고 말하나"는 알고 계셔야 합니다.

뭐가 뭔가

  • 클로드(Claude) — 이 프로젝트의 설계·조사·문서·수집 프로그램을 만든 AI. 사장님이 대화하듯 지시해서 씁니다.
  • 코덱스(Codex) — 코드와 화면을 만드는 데 쓰는 또 다른 AI. 이 인수인계서 화면도 코덱스가 만들었습니다.
  • 둘 다 "사람이 말로 시키면 컴퓨터 작업을 대신하는 프로그램"입니다. 차이는 회사가 다르다는 것뿐이고, 이 프로젝트에선 둘 다 같은 규칙 파일(HANDOFF.md)을 읽고 일합니다.

판매자님이 직접 시켜보고 싶을 때 — 말하는 법

AI는 구체적으로, 하나씩 말하면 잘 알아듣습니다. 예:

  • ✅ "카탈로그 페이지에서 품절 상품을 맨 아래로 내려줘"
  • ✅ "공지문에 배송비 문구를 맨 위로 옮겨줘"
  • ✅ "이 화면 캡처 보고 왜 멈췄는지 설명해줘" (캡처 붙이기)
  • ❌ "알아서 좋게 해줘" — 뭘 원하는지 AI도 모릅니다

AI에게 절대 주지 말 것

  • 키즈빌리지 비밀번호, 통장 번호, 고객 이름·주소·전화번호
  • "결제해줘", "발주해줘" — 돈이 나가는 일은 사람이 누릅니다. 이 프로젝트의 규칙이기도 합니다

처음엔 이렇게

직접 하시기보다 사장님께 말로 요청하시는 게 빠릅니다. 사장님이 AI에게 시켜서 고치고, 판매자님 폴더를 갱신해 드립니다. AI를 직접 쓰고 싶어지면 그때 사장님이 설치를 도와드립니다.
