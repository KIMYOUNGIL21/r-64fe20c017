  1. AI 웹사이트에 로그인 → 프로필에서 설정 열기 → 커넥터(연결) 메뉴 찾기 (메뉴 이름이 가끔 바뀝니다 — "커넥터"나 "연결"이라는 말을 찾으세요)
  2. 목록에서 Notion을 찾아 연결 누르기 → 노션 로그인 창이 뜨면 허용
  3. 어느 페이지를 보여줄지 묻는 창이 뜨면 작업일지 페이지를 선택

연결됐으면 바로 부려봅니다:

붙여넣을 말

② 이 경험으로 쓸 수 있는 블로그 글감 10개를 뽑아줘

글감 제목은 "나 같은 왕초보가 검색할 법한 말"로 지어줘.
(예: 50대도 되나요, 코딩 하나도 몰라도 되나요 같은)
다 되면 글감 10개를 내 노션에 새 페이지로 저장해줘.

내가 흘려 쓴 기록에서 글감 10개가 나오는 순간 — 기록하는 이유를 몸으로 알게 됩니다.

⚠️ 연결 기능은 계정 종류에 따라 되는 범위가 다를 수 있습니다. 연결 메뉴가 안 보이거나 막히면 우회로 — 노션 일지를 전체 선택해 복사한 다음, 대화창에 붙여넣고 위와 똑같이 시키면 됩니다. 오늘의 목표는 연결 자체가 아니라 글감 10개입니다. AI가 노션에 직접 저장을 못 해주면, 글감 10개를 복사해 내 손으로 붙여넣어도 오늘은 성공입니다.

어제 수집기를 그대로 옮기는 건 아닙니다 — 워커는 다른 동네라서, 같은 일을 하는 코드를 새로 받습니다. 새로 짜는 건 AI 몫이니 걱정 마세요.

📍 시작 전에 두 가지. ① 먼저 아래 "붙여넣을 말"로 코드부터 받아두고 1번을 시작하세요 — 3번 단계에서 그 코드를 붙여넣습니다. ② 1주차 주말 보너스로 "물어보면 답하는 봇"을 만들었다면 오늘부터 꺼두세요. 한 봇은 한 가지 방식으로만 들을 수 있어서, 켜둔 채 오늘 것을 연결하면 둘 다 조용히 먹통이 됩니다. 오늘 만드는 것이 그 역할을 이어받습니다.
  1. 클라우드플레어 가입 (무료, 카드 등록 없음)
  2. Workers 메뉴 → Create(만들기) → 이름 짓고 Deploy(올리기 버튼) (전부 영어 화면이지만 오늘 누를 버튼은 이게 다입니다)
  3. AI가 준 코드를 붙여넣고 다시 Deploy
  4. Settings에서 Secret이라는 말이 붙은 메뉴를 찾아 봇 토큰·챗 ID 넣기 (지난주 금고와 같은 개념. 메뉴 이름이 가끔 바뀝니다 — "Secret"을 찾으세요)
  5. AI가 준 연결 주소를 브라우저 주소창에 붙여넣고 엔터 → 화면에 "ok":true 가 뜨면 연결 완료
