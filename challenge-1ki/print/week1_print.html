미리 알아두시면 좋은 것

  • 코드를 직접 짜지 않습니다. 시킬 말을 그대로 드립니다. 여러분이 하는 일은 복사·붙여넣기 · 버튼 누르기 · 파일 이름 정확히 치기 세 가지입니다.
  • 클로드든 코덱스든 상관없습니다. 둘 다 VS Code 안에서 쓰고, 시키는 말도 똑같습니다.
  • 막히는 건 실패가 아닙니다. 에러 화면을 통째로 AI에게 보여주고 "이렇게 나오는데 어떻게 해?"라고 묻는 것, 이게 이번 주에 배우는 가장 중요한 기술입니다.
  • 가입할 곳: 텔레그램 · 깃허브 · 쓰레드 · 노션 — 전부 무료, 카드 등록 없음. (참가 조건인 AI 도구 구독만 별도입니다)
  • Day 1과 Day 3은 컴퓨터 앞에서 하셔야 합니다. 나머지는 짬 내서 조금씩도 됩니다.
  • 결과물이 허접해도 완주입니다. 예쁜 걸 만드는 주가 아니라, 끝까지 가보는 주입니다.
