04 시황 키트 오늘 완료

1주차 트랙 B(자동화)의 척추. 화요일에 받아서 한 번 돌리고, 수요일에 깃허브 액션에 얹습니다.

왜 키트로 고정했나. 시황을 어디서 가져올지 각자 AI에게 맡기면 10명이 10가지 구현이 됩니다. 전형적 실패는 "내 컴퓨터에선 되는데 깃허브 액션에선 IP가 막혀 안 됨" — 1인 케어가 감당 못 하는 폭탄이라 검증된 키트 하나로 통일했습니다.

✔ 양쪽에서 실측 검증

국내 PC(Win11 · Python 3.12) 통과
깃허브 액션(미국 버지니아 IP · Azure) 통과

주 소스 6종 + 예비 소스 3종 전부 응답, 텔레그램 경로 정상, 한국시간 변환 정확(UTC 09:38 → 오후 6시 38분).

✔ 설치할 프로그램 0개

파이썬 표준 기능만 씁니다. pip install 단계를 없앤 게 왕초보 실패 지점 하나를 통째로 지운 겁니다.

주 소스 = 야후 파이낸스 / 예비 = 네이버·프랑크푸르터·업비트. 한 항목이 실패해도 나머지는 발송됩니다.

실측으로 잡은 버그 3건 — 특히 첫 번째.
  • 깃허브 액션은 job 이름에 한글을 못 씁니다. jobs: 보내기: 로 쓰면 워크플로 파일 자체가 거부됩니다. 못 잡았으면 수요일에 10명 전원이 같은 벽에 부딪혔습니다.
  • 야후의 chartPreviousClose는 전일 종가가 아닙니다. 그대로 쓰면 코스피가 −5.98% 대신 −16.7%로 찍힙니다. 종가 배열에서 직접 계산하도록 고치고 네이버 공식 수치와 6종목 대조(오차 0.004%p)했습니다.
  • 관심종목 중복 출력 · 야후가 이름 대신 쓰레기값을 주는 문제 — 둘 다 수정.

🛡 케어 부담을 줄이려 넣은 것

점검.py — 뭐가 되고 안 되는지 한 화면에 찍어줍니다. 토큰이 ●●●●로 가려져서 캡처를 단톡방에 그대로 올려도 안전합니다.

오류 번역 — chat not found → "봇에게 /start 먼저 보내세요"처럼 손댈 수 있는 말로 바꿔 보여줍니다.

AI 가드레일 — README 하단에 "이 키트를 고치는 AI에게" 기술 메모. AI가 친절하게 yfinance로 갈아엎어 액션에서 터지는 걸 막습니다.

열쇠 유출 2중 방어 — .gitignore가 설정 파일을 빼고(실측 확인), 점검 화면은 토큰을 마스킹합니다.

남은 것 2가지. ① 임시 검증 저장소 sihwang-kit-verify 삭제(권한 문제로 사장님이 직접) ② 사장님 봇으로 액션 실발송 리허설 1회 — 액션에서는 텔레그램 서버 도달까지만 확인했습니다.
