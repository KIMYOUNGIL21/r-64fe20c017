먼저 어제 시작한 렌더링 상태를 확인해줘. 멈췄으면 완성된 플리 다음 번호부터 다시 이어서 돌리고, 같은 영상을 중복으로 만들지 마.
렌더링은 계속 진행하게 두고, 이제 내 채널 썸네일을 도와줘.

나는 디자인을 모르는 왕초보야. 먼저 한 번에 질문 하나씩 물어봐줘.
1. 누가 듣는 채널인지
2. 언제 듣는 음악인지
3. 어떤 기분을 주고 싶은지
4. 사진 중심인지 그림 중심인지
5. 썸네일에 글자를 넣을지

답을 들은 뒤 내 채널만의 썸네일 방향 3개를 쉬운 말로 제안해줘. 남의 썸네일을 복사하지 마.
각 방향은 1280×720 크기, 작은 휴대전화 화면에서도 중심 대상이 보이게 설계해줘.

네가 이미지를 직접 만들 수 있으면 시안 3장을 만들어줘.
직접 만들 수 없으면 멈추지 말고, 이미지 생성 도구에 넣을 정확한 문장 3개를 만들어주고 단순한 도형과 글자로 된 로컬 시안도 만들어줘.

2. 기준 한 장을 고르고 변형을 만드세요

썸네일 시안 3장을 작은 크기로 나란히 보여줘.
내가 번호를 고르면 그 시안을 기준 썸네일로 저장해줘.
같은 채널처럼 보이되 색·장면·중심 대상을 다르게 한 변형 3장도 만들어줘.
모든 파일이 1280×720인지 확인하고 「썸네일완성」 폴더에 저장해줘.
같은 채널처럼 보여야 하지만 똑같으면 안 됩니다.
폰 크기로 줄였을 때 중심 대상이 바로 보이고, 각 영상의 장면과 색에는 차이가 있어야 합니다.
