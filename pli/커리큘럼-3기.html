오늘 성공 화면

1. 받은 ZIP을 공장으로 준비하세요

  1. ZIP은 직접 풀지 말고 Orca에 아래 문장을 붙여넣으세요

내 다운로드 폴더에서 플리공장_셋팅코드.zip을 찾아 현재 Orca에서 열어 둔 프로젝트 폴더에 설치해줘.
이미 설치되어 있으면 내 파일을 덮어쓰지 말고 빠진 것만 확인해줘.
설치 뒤 AGENTS.md, CLAUDE.md, 공장.py, 업로더.py, 설정.json, 재료 폴더가 바로 아래에 있는지 확인하고 점검.py를 고쳐줘 모드로 실행해줘.
모두 정상이면 「✅ 공장 준비 완료」라고 말해줘. ZIP을 못 찾으면 내가 해야 할 행동 하나만 알려주고 기다려줘.

2. 열린 크롬에서 유튜브에 직접 로그인하세요

  1. 먼저 Orca에 로그인 창을 열어 달라고 하세요

유튜브 로그인 창을 열어줘.
로그인은 내가 직접 할게. 끝나면 YouTube Studio가 열리는지 확인해줘.

  1. AI가 크롬을 열면 유튜브 계정으로 로그인하세요

    비밀번호와 인증번호는 크롬 창에만 입력합니다.

  2. Orca에 「✅ 로그인 확인!」이 나오면 성공입니다

    크롬 창이 닫혀도 정상입니다.

3. 샘플 자동화를 실행하세요

  1. 바로 아래 문장을 Orca에 붙여넣으세요

샘플 재료로 연습 영상을 만들어줘.
완성되면 유튜브에 비공개로 올리고, 비공개인지 확인해줘.

  1. AI가 제목 번호를 물으면 마음에 드는 번호를 고르세요

    모르겠으면 「1번으로 해줘」라고 답하면 됩니다.

  2. 크롬이 혼자 움직일 때 기다리세요

    마우스와 키보드를 건드리지 않습니다. 1~10분 걸릴 수 있습니다.

  3. YouTube Studio의 「콘텐츠」를 확인하세요

오늘 성공 화면

시작 전에 딱 세 가지만 확인하세요.
크롬에서 Suno(수노)에 로그인하고, 내 플랜·남은 크레딧·컴퓨터의 빈 저장 공간을 AI에게 확인시킵니다. 500곡은 재생성 여유까지 생각하면 크레딧이 빠듯할 수 있습니다.
노래를 만들기 전에 준비 상태만 확인해줘.
1. 재료 폴더의 「오늘이 제일 좋은 날」 샘플 음원·가사·배경·썸네일을 샘플보관 폴더로 옮겨줘. 삭제하지 말고, 재료 폴더에 샘플이 하나라도 남으면 준비 완료라고 말하지 마
2. 지금 Suno에 로그인되어 있는지
3. 현재 플랜과 남은 크레딧으로 오늘 10곡과 이후 대량 생산이 가능한지
4. 곡창고와 백업 위치를 만들 수 있는지, 저장 공간이 충분한지. 가능하면 백업은 다른 드라이브나 클라우드에 잡아줘
5. 유료 플랜에서 만든 곡인지 생성일과 함께 기록할 준비가 되었는지
6. 오늘 영상을 만들 때 재료 폴더에는 최종 선택한 내 노래 10곡과 이번 배경·썸네일만 들어가도록 준비됐는지
문제가 있으면 쉬운 말로 지금 해결할 것 하나만 알려줘. 이상 없으면 「준비 완료」라고 말해줘.

1. 나의 노래 주문서

잘 모르겠으면 기본값 그대로 사용해도 됩니다. AI는 채널의 큰 느낌은 고정하고, 곡마다 필요한 부분만 바꾸게 됩니다.

위에서 원하는 느낌을 고른 뒤 「내 주문 문장 만들기」를 눌러 주세요.

2. 만들어진 주문 문장을 Orca에 붙여넣으세요

  1. AI 질문에는 번호로 답해도 됩니다

    AI가 한 번에 질문 하나만 합니다. 예: 「2번이 좋아」

  2. AI가 먼저 10곡의 방향을 보여주면 확인하세요

    마음에 들면 「이대로 만들어줘」, 다르면 평소 말로 고쳐 달라고 합니다.

  3. Suno에서 곡을 만드는 동안 기다리세요

    로그인·결제·캡차가 나오면 본인이 처리합니다. 그 외에는 마우스와 키보드를 건드리지 않습니다.

  4. 내 컴퓨터에 음원 파일 10개가 있는지 확인하세요

    Suno 화면에 보이는 곡은 아직 완료가 아닙니다. A/B 두 버전은 함께 받을 수 있지만 한 쌍이라고 기록해 같은 플레이리스트에는 넣지 않습니다.

  5. AI가 영상 제작과 유튜브 예약을 마칠 때까지 기다리세요

    배경이나 첫 공개 날짜를 물으면 원하는 답을 고릅니다. 모르겠으면 「가장 쉬운 방법으로 해줘」라고 합니다.

  6. YouTube Studio에서 「예약됨」을 확인하세요

지금까지 만든 결과를 확인해줘.
1. 플레이리스트에 사용할 음원 파일이 10개인지
2. 첫 플레이리스트 영상이 완성됐는지
3. 사용한 10곡을 곡창고의 사용완료_플리01 폴더로 옮겼는지
4. 곡마다 Suno 주소 또는 ID, 생성일, 플랜, A/B 짝이 곡목록.csv에 기록됐는지
5. 사용한 10곡과 추가로 받은 A/B 후보까지 모두 백업 폴더에 있는지
6. YouTube Studio에서 예약됨인지
하나씩 확인하고 결과만 쉬운 말로 알려줘.

내 컴퓨터의 실제 음원 파일, 곡목록, 백업의 숫자가 서로 같아야 합니다. 목표는 최대 500곡입니다.
10+어제 받은 곡

0오늘 만들 영상
생성만 하고 다운로드를 미루면 안 됩니다.
20곡을 만들 때마다 바로 내 컴퓨터에 받고 백업합니다. 9월 3일에는 다운로드 제한이 시작될 수 있으므로 오늘 밤 안에 끝내는 것이 가장 안전합니다.

아래 문장 하나로 생산을 시작하세요

AI가 채널의 정체성은 지키고, 반복되는 노래는 줄이도록 설계한 명령입니다.

오늘은 노래 생산과 다운로드만 해줘. 영상 렌더링·썸네일·유튜브 업로드는 절대 하지 마.

목표는 샘플을 제외한 내 로컬 음원 파일을 최대 500개까지 안전하게 확보하는 거야. Suno 보관함의 곡 수가 아니라 내 컴퓨터에 실제로 받은 파일만 세어줘.

나는 음악 용어를 모르는 왕초보야. 아래 규칙은 네가 관리해줘.
1. Day 2 주문서에서 듣는 상황·주는 기분·음악 종류·가사 언어·사용자가 고른 보컬 범위·전체 소리 느낌은 「채널 고정 기준」으로 정해서 나의노래설계.md에 저장해줘.
2. 모든 곡을 똑같게 만들지 마. 20곡마다 곡 구조·주요 악기·정해진 범위 안의 속도·에너지·보컬 표현·첫 부분 길이 중 2~3가지만 바꾸고, 채널 고정 기준은 유지해줘.
3. 특정 가수·기존 곡·기존 가사를 따라 하지 마. 제목, 후렴 핵심 문장, 가사 첫 줄이 앞 곡과 비슷하면 새로 써줘.
4. 첫 부분이 지나치게 길거나, 가사가 뭉개지거나, 끝이 잘리는 실패를 줄이도록 작사스킬 기준을 지켜줘.
5. Suno가 A/B 두 버전을 만들면 둘 다 받을 수 있지만 같은 「짝 번호」를 기록해줘. 한 짝의 두 곡은 나중에 같은 플레이리스트에 넣지 마.
6. 20곡을 만들 때마다 즉시 음원 파일로 다운로드해 「곡창고\2026-09-02\묶음번호」에 저장하고, 똑같은 파일을 백업 위치에도 복사해줘. 다른 드라이브나 클라우드 백업 위치가 없으면 로컬 「백업\2026-09-02\묶음번호」에 우선 복사하고, 같은 컴퓨터라 완전한 백업은 아니라고 한 번만 알려줘. 재료 폴더에는 넣지 마.
7. 파일 이름은 묶음번호·짝번호·A/B·제목이 보이게 일정하게 붙여줘. 원래 Suno 제목과 주소 또는 ID는 잃어버리지 마.
8. 기록\곡목록.csv에 파일명, 같은 파일 확인용 지문, Suno 주소 또는 ID, 생성일, 생성 당시 플랜, 묶음번호, 짝번호, A/B, 제목, 가사 첫 줄 또는 후렴 핵심 문장, 느낌, 주요 악기, 보컬, 속도, 길이를 남겨줘.
9. 매 20곡마다 파일이 열리는지, 너무 짧거나 소리가 거의 없는지, 완전히 같은 파일인지 확인해줘. 이상한 파일은 삭제하지 말고 「검토필요」로 복사해 표시해줘.
10. 매 20곡이 끝나면 로컬 실제 파일 / 곡목록 / 백업 숫자가 같은지 확인하고 「현재 몇 곡 / 최대 500곡」만 알려준 뒤 계속해줘.
11. 중간에 멈추거나 다시 시작해도 현재 로컬 파일과 곡목록을 먼저 세고 부족한 수만 이어서 만들어줘. 이미 받은 곡은 다시 만들거나 다시 받지 마.
12. 로그인·결제·캡차·크레딧 부족·저장 공간 부족이 나올 때만 나를 불러줘. 내 허락 없이 크레딧을 구매하지 말고, 숫자를 채우지 못했는데 완료라고 말하지 마.

시작하기 전에 현재 로컬 음원 수, 남은 크레딧, 예상 가능한 최대 곡 수를 먼저 한 줄로 알려주고 바로 시작해줘.

2. AI에게 기술 검사와 음악 검사를 맡기세요

- 소리가 거의 없거나 심하게 찢어지는지
- 완전히 같은 파일이 중복됐는지
- 시작이나 끝이 갑자기 잘린 것으로 의심되는지

- 가사가 뭉개지거나 마지막 문장이 덜 불린 것으로 의심되는 곡
- A/B 한 짝인 곡: 둘 다 좋아도 같은 플레이리스트에는 넣지 않도록 표시
- Suno 주소 또는 ID, 생성일, 생성 당시 유료 플랜 기록이 없는 곡

음악을 실제로 들을 수 있으면 각 곡의 첫 부분·중간 후렴·마지막 부분을 짧게 확인해줘. 들을 수 없으면 들었다고 말하지 말고 「직접 확인」으로 보내줘.

결과는 세 상태로 나눠줘.
1. 사용 가능: 기술 문제가 없고 채널 기준에 맞는 곡
2. 직접 확인: 애매하거나 사람이 한 번 들어봐야 하는 곡
3. 제외 후보: 파일 오류·심한 중복·명확한 실패가 의심되는 곡

파일은 상태별 폴더에 복사해 정리하고 원본과 백업은 그대로 둬. 기록\곡목록.csv에 품질 상태와 이유를 추가하고, 전체 / 사용완료 / 사용 가능 / 직접 확인 / 제외 후보 수를 기록\곡재고현황.md에 저장해줘.
사용 가능 400곡은 방향이지 합격선이 아닙니다.
숫자를 맞추려고 애매한 곡을 통과시키지 않습니다. 직접 확인과 제외 후보도 삭제하지 않아야 나중에 다시 판단할 수 있습니다.
