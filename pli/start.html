유튜브 플리 자동화 챌린지 · 시작 전 설치

설치, 이것만 따라 하면
끝납니다

전부 해서 약 20~30분. 여러분이 직접 하는 큰일은 붙여넣기 2번 + 로그인 1번이고, 나머지는 화면에 뜨는 [예]·[다음] 버튼만 누르면 됩니다. 막히면 참가방(카카오톡 오픈채팅방)에 화면 사진을 올리세요 — 당일 해결해 드립니다.

0

준비물 확인

  • 윈도우 PC 또는 맥 (이 설명서는 윈도우 기준, 맥은 참가방에서 별도 안내)
  • 클로드 유료 구독 (claude.ai — 월 약 3만원, 챌린지 기간 유지)
  • 구글 계정 (유튜브용 — 나중에 채널 만들 때 씁니다)
  • 메일로 받은 셋팅코드 zip 파일 (아직 안 받았으면 참가방에 말씀해 주세요)
오늘 설치하는 프로그램(깃 · 클로드코드 · 오르카)은 전부 무료입니다 — 돈이 더 나가지 않습니다. 수노(Suno — AI로 노래를 만들어 주는 사이트) 계정은 Day 2에 만들어도 됩니다. 오늘은 없어도 됩니다.
1

파워셸 열기

  1. 키보드에서 윈도우 키를 누릅니다.
  2. 그대로 powershell 이라고 입력합니다. 글자가 한글(ㅔㅐㅈ...)로 나오면 한/영 키를 누르고 다시 치세요.
  3. Windows PowerShell이 검색되면 엔터. 파란색이든 검은색이든 글자를 입력할 수 있는 창이 열리면 맞습니다.
스크린샷 자리 ① — 시작 메뉴에서 powershell 검색 화면
2

설치 한 줄 붙여넣기

아래 한 줄을 복사해서, 방금 연 창에 붙여넣고(마우스 오른쪽 클릭이 붙여넣기입니다) 엔터를 누르세요. 그러면 필요한 무료 프로그램 — 깃(Git), 클로드코드, 오르카(Orca — 클로드에게 말을 거는 프로그램) — 를 창이 알아서 설치합니다.

irm https://raw.githubusercontent.com/KIMYOUNGIL21/r-64fe20c017/main/pli/setup.ps1 | iex
중간에 화면이 어두워지며 "이 앱이 디바이스를 변경하도록 허용하시겠습니까?" 라고 물으면 [예]를 누르세요. 정상이고, 여러 번 나올 수 있습니다. 무료 프로그램 설치를 허락하는 것뿐입니다.
보통 5~10분 걸립니다. 초록색 [OK]가 하나씩 늘어나고, 글자가 한동안 안 움직여도 정상이니 창을 닫지 마세요. 중간에 Orca 설치 창이 뜨면 [다음]을 눌러 설치를 마치세요. 노란 [!]가 뜨면 그 문장을 그대로 따라 하면 됩니다.
스크린샷 자리 ② — [OK]가 쌓인 설치 창
스크린샷 자리 ③ — "디바이스 변경 허용" 경고창 ([예] 표시)
3

클로드 로그인

설치가 끝나면 검은 새 창이 저절로 열리고, 클로드가 시작됩니다. (1~2분 기다려도 안 열리면 참가방에 사진을 올리세요.) 안내는 영어지만 아래 순서대로만 누르면 됩니다:

  1. 글자 색/스타일을 고르는 화면이 나오면 → 그냥 엔터.
  2. 로그인 방법을 고르는 화면이 나오면 → 맨 위의 "Claude account with subscription"(구독 계정)에서 엔터. ⚠️ 아래쪽 Console(콘솔) 계정을 고르면 요금이 따로 나가는 방식이니 고르지 마세요.
  3. 브라우저가 열리면 유료 구독한 그 클로드 계정으로 로그인하고 [승인/Authorize]를 누르세요.
  4. 검은 창으로 돌아와 로그인 성공 문구가 보이는 것까지 확인한 뒤에 그 창을 닫으세요. 이 로그인은 딱 한 번이면 됩니다.
스크린샷 자리 ④ — 검은 창의 로그인 방법 선택 화면 (맨 위 항목에 화살표)
4

오르카 열고, 공장 폴더 만들기

바탕화면(또는 시작 메뉴)에서 Orca(오르카)를 실행하세요.

  1. 처음 실행하면 홈 폴더 접근을 허용해 달라는 안내가 나옵니다 — 허용하세요.
  2. 작업할 폴더를 추가하는 화면에서 폴더 선택 창이 열리면, 왼쪽 목록에서 내 PC → 로컬 디스크 (C:)를 누르고, 위쪽 [새 폴더] 버튼으로 "플리공장" 폴더를 만들어 선택하세요.
    (바탕화면이나 문서 폴더에 만들면 나중에 경로 문제가 생길 수 있어 C 드라이브에 만듭니다)
  3. 플리공장이 열리고 클로드에게 말을 걸 수 있는 입력창이 보이면 성공입니다.
스크린샷 자리 ⑤ — 폴더 선택 창: 내 PC → 로컬 디스크(C:) → [새 폴더] 경로
스크린샷 자리 ⑥ — 오르카에서 플리공장 폴더가 열린 화면
5

셋팅코드 zip 내려받기

메일로 보내드린 셋팅코드 zip에서, 첨부 파일 옆의 다운로드(↓) 버튼을 누르면 다운로드 폴더에 저장됩니다. 더블클릭해서 열 필요는 없습니다 — 다음 단계에서 클로드가 알아서 풉니다.

6

마지막 — 이 지시문을 클로드에게 붙여넣기

오르카의 입력창에 아래 지시문 전체를 복사해 붙여넣고 엔터. 클로드가 나머지 설치(ffmpeg · 파이썬 — 영상을 만드는 무료 도구들)와 공장 조립을 스스로 끝내고, 검사 결과표를 보여줍니다.

지금부터 너는 내 유튜브 플레이리스트 영상 공장의 기술자야. 나는 코딩을 전혀 못 하니까, 작업은 전부 네가 하고 나한테는 결과와 다음 행동만 한국어로 알려줘.

오늘은 공장 설치의 날이야. 순서대로 해줘.
1. winget으로 ffmpeg와 Python을 설치해줘. 이미 있으면 건너뛰고, 설치 후 새 터미널이 필요하면 네가 알아서 처리해줘.
2. 내 윈도우 다운로드 폴더에서 이름에 "셋팅코드"가 들어간 zip 파일을 찾아서, zip 안의 파일들이 지금 열려 있는 이 폴더 바로 아래에 오도록 풀어줘 (CLAUDE.md, 공장.py, 설정.json이 이 폴더에 바로 보여야 해). 못 찾으면 "메일에서 셋팅코드 zip을 다운로드해 주세요"라고 말하고 기다려줘.
3. "재료", "완성", "기록" 폴더가 없으면 만들어줘.
4. 자가진단을 돌려줘: ffmpeg 버전, Python 버전, 폴더 3개, 셋팅코드 파일들이 제대로 있는지 검사해서 결과를 한글 표(항목/상태)로 보여줘.
5. 전부 통과면 마지막 줄에 크게 "✅ 공장 준비 완료"라고 쓰고, 시작하세요.md 내용을 세 줄로 요약해서 "앞으로 이렇게 쓰시면 됩니다"라고 알려줘. 하나라도 실패면 뭘 해야 하는지 코딩 처음 하는 사람 기준으로 알려줘.
진행 중에 클로드가 "실행해도 될까요?" 하고 허락을 물을 수 있습니다(영어 버튼). 허용/Yes를 누르세요. 오늘 설치 중에 묻는 것들은 전부 허용해도 됩니다.
스크린샷 자리 ⑦ — 클로드가 허용을 묻는 화면 (누를 버튼 표시)
"✅ 공장 준비 완료"가 보이면 끝!
그 화면을 캡처해 참가방에 올리면 세팅 인증 완료입니다.
(캡처: 윈도우 키+Shift+S. 어려우면 휴대폰으로 화면을 찍어도 됩니다) 인증 후, 클로드가 요약해 준 "시작하세요" 안내를 읽어 보세요 — 앞으로 공장을 쓰는 법이 3줄로 정리돼 있습니다. 이제 Day 1 미션을 기다리시면 됩니다.
스크린샷 자리 ⑧ — "✅ 공장 준비 완료" 최종 화면 (성공 기준 사진)
?

막혔을 때 (순서대로)

  1. 1~3단계(오르카를 켜기 전)에서 막혔으면 → 바로 참가방에 화면 사진을 올리세요. 당일 안에 같이 해결합니다.
  2. 4단계 이후, 빨간 에러 글자가 나오면 → 그 글자를 통째로 복사해서 클로드 입력창에 붙여넣고 "이 에러 고쳐줘"라고 쓰세요. 대부분 여기서 풀립니다.
  3. 클로드도 못 풀면 → 참가방에 화면 사진. 설치 한 줄(2단계)은 여러 번 실행해도 안전합니다 — 이미 설치된 건 건너뜁니다.
