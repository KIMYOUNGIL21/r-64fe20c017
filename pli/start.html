먼저, 내가 쓸 AI를 골라볼게요

아래에서 평소 사용하는 AI 이름 하나만 눌러 주세요. 누른 뒤에는 그 AI에 필요한 안내만 보이니 편하게 따라오시면 됩니다.

위의 두 버튼 중 하나를 누르면 다음 안내가 열립니다.

0

오늘 할 일을 먼저 볼게요

크게 두 가지입니다 — ① 컴퓨터에 프로그램 깔기 ② 필요한 계정 만들어두기. 그게 전부입니다.

  1. 영상 만들기는 오늘 안 합니다. 시작하는 날 다음 안내서를 드립니다.
  2. 오늘은 받으실 파일이 없습니다. 챌린지에 쓸 파일은 시작하는 날 따로 드립니다.
  3. Orca는 AI에게 일을 부탁하는 작업 창입니다. 여기서 한국어로 말하면 됩니다.
  4. Git, 파이썬, ffmpeg 같은 낯선 이름이 지나가도 괜찮습니다. 영상 공장에 들어갈 부품이고, 외우실 필요 없습니다.
각 단계 아래에 체크 칸이 있습니다. 끝낼 때마다 눌러 주세요. 맨 위 막대가 차오르고, 컴퓨터를 껐다 켜도 체크한 것은 그대로 남습니다. 전부 채우면 마지막에 참가방에 올릴 문구가 나옵니다.
1

시작 전에 필요한 것

  • 인터넷이 연결된 내 윈도우 PC. 프로그램을 설치할 수 있는 본인 컴퓨터여야 합니다.
  • 클로드 또는 코덱스 유료 구독 계정. 둘 중 하나만 있으면 됩니다 (참가 조건입니다).
  • 구글 계정. 유튜브를 쓸 계정입니다. 없으면 지금 하나 만들어 두세요.
  • 로그인할 때 쓸 이메일과 비밀번호, 인증번호를 받을 휴대폰.
  • 넉넉한 1시간~1시간 30분. 설치가 도는 동안은 기다리는 시간이 많습니다.
이 페이지는 설치할 윈도우 PC에서 열어 주세요. 휴대폰으로 보고 계시면, 그 PC에서 이 링크를 다시 열어야 복사 버튼을 쓸 수 있습니다.
2

파워셸 창을 열어볼게요

파워셸은 컴퓨터에게 설치를 부탁하는 창입니다. 파란색이나 검은색 화면이 열려도 놀라지 않으셔도 됩니다.

  1. 키보드 왼쪽 아래의 윈도우 모양 키를 한 번 눌러 주세요.
  2. 그대로 powershell을 영어로 입력해 주세요. 한글로 입력되면 한영 키를 누른 뒤 다시 적으면 됩니다.
  3. Windows PowerShell을 한 번 눌러 주세요.
  4. 파란색 또는 검은색 창이 열리면 잘하신 겁니다. 창은 그대로 두고 다음 단계로 가면 됩니다.
비슷한 이름이 여러 개 나옵니다. 여기서 자주 멈춥니다. 저도 처음엔 엉뚱한 걸 열었습니다.
PowerPoint · PowerToys · Power Automate 는 아닙니다.
Windows PowerShell (x86) 이나 Windows PowerShell ISE 도 아닙니다.
맨 위 최고의 매치 자리에 나온 Windows PowerShell 하나만 누르세요.
"관리자로 실행"은 누르지 않으셔도 됩니다. 그냥 이름을 바로 누르거나 오른쪽의 [열기]를 누르면 됩니다.

여기서부터는 내가 쓸 AI에 따라 달라집니다

3단계는 클로드를 쓰는 분과 코덱스를 쓰는 분의 설치 방법이 다릅니다. 아래에서 하나를 고르시면 그 방법만 여기에 나타납니다. 나머지는 안 보이니 헷갈릴 일이 없습니다.

평소 쓰시는 것을 눌러 주세요

둘 중 뭘 쓰는지 모르시겠다면 — 이 챌린지 신청하실 때 결제하신 쪽입니다. 클로드(Claude)를 결제하셨으면 왼쪽, ChatGPT를 결제하고 코덱스를 쓰신다면 오른쪽입니다.
잘못 골라도 괜찮습니다. 위로 올라가 다시 누르면 바로 바뀝니다.

클로드와 필요한 프로그램을 한 번에 설치할게요

아래 버튼을 누른 뒤, 파워셸 창 안을 한 번 누르고 마우스 오른쪽 버튼을 눌러 주세요. 글이 붙으면 Enter를 한 번 누르면 됩니다.

아래 글은 읽지 않으셔도 됩니다. 영어와 기호가 잔뜩 섞여 있는데 신경 쓰지 마세요. 복사 버튼만 누르시면 됩니다. 사람이 아니라 컴퓨터가 읽을 글입니다.
$env:PLI_AI='claude'; irm https://raw.githubusercontent.com/KIMYOUNGIL21/r-64fe20c017/main/pli/setup.ps1 | iex

  2. 글자가 잠시 멈춘 것처럼 보여도 괜찮습니다. 20분 정도는 창을 닫지 말고 기다려 주세요.
  3. 중간에 Orca 설치 창이 열립니다. [다음] · [설치] · [마침] 버튼이 보이면 차례로 눌러 주세요.
    버튼 없이 막대만 차오르다 저절로 끝나기도 합니다 — 그것도 정상입니다.
    설치가 끝나고 Orca가 저절로 열려도 지금은 그냥 두시고, 파워셸 창으로 돌아와 주세요.
  4. 마지막에 설치 결과 표가 나옵니다. 이게 보이면 설치가 끝난 겁니다.
  5. 이어서 검은 로그인 창이 열립니다 — 다음 단계로 가세요.
이 한 줄이 Git · 파이썬 · ffmpeg · Node.js · 크롬 · 클로드코드 · Orca를 순서대로 설치합니다. 이미 깔려 있는 것은 건너뜁니다. 여러 번 실행해도 안전합니다.
표에 "나중에" 라고 적힌 줄이 보여도 전부 정상입니다. 몇 개든 상관없습니다.
· 셋팅코드 — 시작하는 날 메일로 드리는 파일입니다. 지금 없는 게 맞습니다.
· 구글 열쇠 — 아래 8단계에서 직접 만드실 것입니다. 지금은 없는 게 맞습니다.
· 수노 브라우저 — 이게 "나중에"로 뜨는 경우도 있는데, 챌린지 시작하는 날 AI가 알아서 채웁니다.
「앱 설치 관리자가 없는 PC입니다」라고 나오고 스토어 창이 열리면 — 그 스토어에서 [설치](또는 [가져오기])를 누르고 끝날 때까지 기다리세요. 그다음 파워셸로 돌아와 엔터를 누르고, 설치 한 줄을 처음부터 다시 실행해 주세요.
노란 글씨가 보여도 놀라지 마세요. 색이 아니라 글자를 보시면 됩니다.
「나중에」도 노란색으로 나오는데 그건 정상입니다. 다시 실행해야 하는 건 「확인 필요」·「재실행 필요」 이 두 가지뿐입니다.
표 오른쪽 칸에 그 두 글자가 보이면 이 창을 닫고 설치 한 줄을 한 번 더 실행해 주세요. 표 아래에 「아직 확인이 필요한 것:」 이라는 줄도 함께 나옵니다.
이미 된 것은 건너뛰어 금방 끝납니다. 새로 깐 프로그램은 창을 다시 열어야 인식되는 경우가 많아서, 두 번째 실행에서 대부분 풀립니다.
표에 「Orca — 직접 설치」라고 적힌 줄이 보이면 — 인터넷 창이 하나 저절로 열렸을 겁니다(영어 페이지입니다). 그 페이지에서 Windows라고 적힌 버튼을 눌러 파일을 받으세요. 받은 파일을 두 번 누르고 [다음] · [설치] · [마침]을 차례로 누르면 끝입니다. 그다음 파워셸로 돌아와 설치 한 줄을 한 번 더 실행해 주세요.

내 AI에 로그인할게요

앞 단계 마지막에 검은 창이 새로 열렸을 겁니다. 그 창에서 로그인해 주세요. 안내에 따라 브라우저가 열리면 평소 쓰는 계정으로 로그인하면 됩니다.

검은 창이 열리지 않았을 때만 아래를 복사해 파워셸에 붙여넣고 Enter를 눌러 주세요.

claude

codex login
이번에 처음 결제하신 분은 여기를 꼭 읽어 주세요.
로그인은 결제하신 바로 그 계정으로 해야 합니다. 평소 쓰던 다른 이메일로 로그인하면 무료 계정으로 들어가서 챌린지 중에 막힙니다.
헷갈리시면 인터넷 창(크롬·엣지)에서 claude.ai에 들어가 보세요. 거기 로그인돼 있는 계정이 결제하신 계정입니다. 헷갈리시면 인터넷 창(크롬·엣지)에서 chatgpt.com에 들어가 보세요. 왼쪽 아래에 뜨는 계정이 결제하신 계정입니다.
로그인 전에 영어 질문이 한두 개 먼저 나올 수 있습니다 — 놀라지 마세요.
화면 색을 고르라는 질문입니다. 화살표 키(↑↓)로 아무거나 고르고 Enter를 누르면 지나갑니다. 마우스가 아니라 키보드를 씁니다. 그 다음에 로그인 안내가 나옵니다.
이런 순서로 흘러갑니다.
① 검은 창에 안내가 뜹니다 → ② 인터넷 창이 저절로 열립니다 → ③ 브라우저에서 로그인하고 [허용] 같은 버튼을 누릅니다 → ④ 다시 검은 창으로 돌아옵니다.
브라우저가 안 열리면 검은 창에 주소가 하나 뜹니다. 그 주소를 복사해 브라우저에 붙여넣으면 됩니다.
검은 창에 로그인 완료 표시가 나오면 끝입니다. 그 창은 닫아도 됩니다.

Orca를 열고 공장 폴더를 골라볼게요

폴더는 이미 만들어져 있습니다. 앞 단계의 설치 한 줄이 C:\플리공장을 만들어 뒀습니다. 여기서는 그 폴더를 고르기만 하면 됩니다.

먼저 알아두실 것 — 이 프로그램은 버튼이 영어입니다. 어떤 영어 글자를 눌러야 하는지 아래에 그대로 적어뒀으니 그것만 찾으시면 됩니다.
  1. 바탕화면에 고래 모양 아이콘이 있는지 먼저 보세요. 그게 Orca입니다.

유튜브 채널을 만들고 전화번호 인증까지 해둘게요

저는 전화번호 인증을 안 해두고 첫 영상을 올렸다가, 썸네일이 안 붙어서 왜 그런지 사흘을 몰랐습니다. 1분이면 끝나는 걸 사흘 미룬 셈입니다.

영상을 올릴 내 채널이 있어야 합니다. 할 일은 두 가지 — 채널 만들기와 전화번호 인증입니다.

① 채널 만들기 — 이미 채널이 있으면 건너뛰세요

  1. 브라우저에서 youtube.com에 들어가 오른쪽 위 동그란 프로필 사진을 누릅니다.
  2. 메뉴에 [내 채널]이 보이면 이미 채널이 있는 것입니다 — ②로 바로 가세요.
  3. [채널 만들기]가 보이면 그걸 누르고, 이름은 아무거나 적고 넘어가세요. 나중에 바꿀 수 있습니다.

② 전화번호 인증 — 주소 하나로 바로 갑니다

  1. 브라우저 주소창에 아래를 붙여넣고 Enter를 누르세요. 메뉴를 타고 들어갈 필요가 없습니다.
  2. 휴대폰 번호를 넣고 문자로 받기를 고른 뒤, 문자로 온 6자리 숫자를 넣으면 끝입니다.
youtube.com/verify
"이미 인증됨"이라고 나오면 예전에 해두신 것이니 그냥 넘어가시면 됩니다.
전화번호 인증은 꼭 해주세요. 이게 없으면 나중에 썸네일이 자동으로 안 붙습니다. 1분이면 끝나고, 지금 해두는 편이 훨씬 편합니다.

유튜브에 자동으로 올릴 "열쇠"를 만들어둘게요

저도 이 화면을 처음 열었을 때 20분을 헤맸습니다. 어려워서가 아니었습니다. 구글이 메뉴 이름을 최근에 바꿔 놓아서, 안내서와 실제 화면이 안 맞았기 때문입니다. 그래서 이번엔 바뀐 이름과 옛 이름을 둘 다 적어 뒀습니다. 화면에 보이는 쪽을 누르시면 됩니다.

먼저 무엇을 하는 건지부터 말씀드릴게요.
내 컴퓨터의 공장이 내 유튜브에 영상을 대신 올리려면, 구글에게 "이 프로그램은 제가 쓰는 게 맞습니다"라고 알려줘야 합니다. 그 절차를 마치면 열쇠 파일이 하나 내려받아집니다. 그 파일을 공장에 넣어두면 끝입니다.

세 가지만 먼저 안심하세요.
· 전부 무료입니다. 카드 등록도 없습니다.
· 내 구글 계정 안에서만 만들어지는 것이고, 남에게 공개되지 않습니다.
· 잘못 눌러도 아무것도 망가지지 않습니다. 마음에 안 들면 지우고 다시 만들면 됩니다.
여기가 오늘 제일 어렵습니다. 그래서 미리 말씀드립니다.
화면이 여섯 번 바뀝니다. 한 화면에서 하는 일은 딱 하나씩이라 그것만 보시면 됩니다. 15~25분 걸립니다.

막히면 그냥 멈추셔도 됩니다. 8번은 시작하는 날 같이 해도 되는 단계입니다. 나머지(9번 수노)까지만 끝내고 멈춘 화면을 사진 찍어 참가방에 올려 주세요. 여기서 포기하지만 않으시면 됩니다.
구글이 최근에 메뉴 이름을 바꿨습니다. 화면에 따라 예전 이름이 보일 수도 있어서, 아래에 두 이름을 같이 적어뒀습니다. 둘 중 보이는 쪽을 누르시면 됩니다.

✅ 복사했으면 성공. 다음 단계에서 이 글자를 파일로 저장합니다.
복사한 걸 잃어버려도 괜찮습니다. 목록에 만들어진 키가 남아 있어서, 그 줄을 눌러 언제든 다시 복사할 수 있습니다.
「API 키」는 열쇠 파일과 다른 물건입니다. 열쇠 파일이 내 채널에 영상을 대신 올리는 허락이라면, API 키는 남의 채널 성적(조회수·길이·올리는 요일)을 읽어 오는 번호표입니다. 2일차에 「이 채널 분석해줘」를 할 때 씁니다. 지금은 저장만 해두시면 됩니다.

마지막 — 받은 열쇠를 제자리에 넣기

  1. 파워셸에서 3단계의 설치 한 줄을 한 번 더 실행해 주세요. 다운로드 폴더에서 열쇠 파일을 알아서 찾아 공장에 넣어 줍니다.
    (파워셸 창을 닫으셨으면 2단계처럼 다시 열고, 3단계의 복사 버튼을 다시 쓰시면 됩니다.)
  2. 복사해둔 API 키를 파일 하나에 저장해 둡니다.
    1. 2단계에서 눌렀던 그 윈도우 모양 키를 누르고 메모장이라고 입력한 뒤, 맨 위에 뜬 메모장을 누르세요. 하얀 빈 창이 열립니다
    2. 그 창 안을 한 번 누르고 마우스 오른쪽 버튼 → 붙여넣기. AIza로 시작하는 긴 글자가 보이면 맞습니다
    3. [파일] → [저장]을 누르면 저장 창이 열립니다. 파일 이름 칸을 한 번 누르고 거기 있던 글자를 지운 뒤, 아래 주소를 통째로 붙여넣고 [저장]을 누르세요. 폴더를 찾아 들어가실 필요가 없습니다 — 5단계에서 쓰신 것과 같은 방법입니다
    C:\플리공장\API키.txt
    ✅ 메모장 창 맨 위에 「API키」라고 뜨면 저장된 겁니다. 이제 메모장은 닫으셔도 됩니다.
이름은 신경 쓰지 않으셔도 됩니다.
메모장에 붙여넣고 [파일] → [저장], 이름은 API키, 저장 위치는 C:\플리공장 이면 끝입니다.
공장은 그 폴더에서 이름에 「키」가 들어간 글 파일을 전부 열어보고 찾아냅니다. API키.txt.txt가 되어도 상관없습니다.
✅ 설치 결과 표에서 「구글 열쇠」 줄의 오른쪽 칸이 「방금 넣음」이면 8번 완료입니다.
이때 검은 창이 하나 더 열립니다 — 놀라지 마세요. 설치 한 줄은 실행할 때마다 로그인 창을 한 번씩 엽니다. 이미 로그인돼 있으면 그 창은 그냥 닫으시면 됩니다. 결과 표는 원래 있던 파워셸 창에 그대로 남아 있습니다.
시작하는 날엔 이 고생을 다시 하지 않습니다. Orca에 "유튜브 연결해줘" 한 마디만 하면, 브라우저에서 [허용] 한 번 누르는 걸로 끝납니다. 오늘 열쇠를 만들어뒀기 때문입니다.
"확인되지 않은 앱"이라는 무서운 경고가 나오면 — [고급] → [이동]을 누르시면 됩니다. 내가 방금 만든 내 앱이라 안전합니다. 구글이 모든 새 앱에 붙이는 문구입니다.

수노에 가입해둘게요

저는 수노 가입을 곡 만드는 날 아침에 하려다 인증 메일이 스팸함에 들어가 있어서 20분을 날렸습니다. 오늘 해두시면 그날은 바로 시작합니다.

수노는 노래를 만들어 주는 사이트입니다. 며칠 뒤 내 곡을 만들 때 쓰는데, 가입만 오늘 해두면 그날 바로 시작할 수 있습니다.

  1. 브라우저에서 suno.com에 들어가 [Sign Up]으로 가입해 주세요. 구글 계정으로 가입하면 비밀번호를 새로 만들지 않아도 됩니다.
  2. 무료로 시작할 수 있습니다. 지금 결제하지 않으셔도 됩니다.
  3. 가입만 확인하고 창을 닫으세요. 곡은 나중에 만듭니다.
무료 플랜은 하루에 만들 수 있는 곡 수에 한도가 있습니다. 마음에 드는 곡이 잘 안 나오면 그날 유료로 올리는 분도 있는데, 지금 정하실 필요는 없습니다.
