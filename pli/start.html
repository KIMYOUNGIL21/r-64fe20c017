Day 0.
컴퓨터와 계정을 준비합니다

챌린지가 시작되기 전에 컴퓨터와 계정을 전부 준비합니다.
오늘 다 해두면 시작하는 날은 아주 가볍습니다. 약 1시간~1시간 30분, 중간에 쉬었다 이어서 해도 됩니다.

할 일 0 / 8 끝냈어요아래 단계를 하나씩 끝내고 체크해 주세요

사용할 AI를 선택하세요

아래에서 평소 사용하는 AI 이름 하나만 눌러 주세요. 누른 뒤에는 그 AI에 필요한 안내만 보이니 편하게 따라오시면 됩니다.

위의 두 버튼 중 하나를 누르면 다음 안내가 열립니다.

0

오늘의 목표와 범위

크게 두 가지입니다 — ① 컴퓨터에 프로그램 깔기 ② 필요한 계정 만들어두기. 그게 전부입니다.

  1. 영상 만들기는 오늘 안 합니다. 시작하는 날 다음 안내서를 드립니다.
  2. Day 0에는 별도 배포 파일이 없습니다. 챌린지용 파일은 Day 1 시작 전에 제공합니다.
  3. Orca는 AI에게 일을 부탁하는 작업 창입니다. 여기서 한국어로 말하면 됩니다.
  4. Git, 파이썬, ffmpeg 같은 낯선 이름이 지나가도 괜찮습니다. 영상 공장에 들어갈 부품이고, 외우실 필요 없습니다.
이 챌린지에서 7일 동안 무엇을 하는지가 궁금하시면 미리 열어 보셔도 됩니다. → 7일 커리큘럼 열기
오늘은 안 읽으셔도 됩니다. 오늘은 컴퓨터 준비만 하시면 됩니다.
각 단계 아래에 체크 칸이 있습니다. 끝낼 때마다 눌러 주세요. 맨 위 막대가 차오르고, 컴퓨터를 껐다 켜도 체크한 것은 그대로 남습니다. 전부 채우면 마지막에 참가방에 올릴 문구가 나옵니다.
1

준비물과 예상 시간

  • 인터넷이 연결된 내 윈도우 PC. 프로그램을 설치할 수 있는 본인 컴퓨터여야 합니다.
  • 클로드 또는 코덱스 유료 구독 계정. 둘 중 하나만 있으면 됩니다 (참가 조건입니다).
  • 구글 계정. 유튜브를 쓸 계정입니다. 없으면 지금 하나 만들어 두세요.
  • 로그인할 때 쓸 이메일과 비밀번호, 인증번호를 받을 휴대폰.
  • 넉넉한 1시간~1시간 30분. 설치가 도는 동안은 기다리는 시간이 많습니다.
이 페이지는 설치할 윈도우 PC에서 열어 주세요. 휴대폰으로 보고 계시면, 그 PC에서 이 링크를 다시 열어야 복사 버튼을 쓸 수 있습니다.
2

Windows PowerShell 열기

파워셸은 컴퓨터에게 설치를 부탁하는 창입니다. 파란색이나 검은색 화면이 열려도 놀라지 않으셔도 됩니다.

  1. 키보드 왼쪽 아래의 윈도우 모양 키를 한 번 눌러 주세요.
  2. 그대로 powershell을 영어로 입력해 주세요. 한글로 입력되면 한영 키를 누른 뒤 다시 적으면 됩니다.
  3. Windows PowerShell을 한 번 눌러 주세요.
  4. 파란색 또는 검은색 창이 열리면 잘하신 겁니다. 창은 그대로 두고 다음 단계로 가면 됩니다.
비슷한 이름이 여러 개 나옵니다.
PowerPoint · PowerToys · Power Automate 는 아닙니다.
Windows PowerShell (x86) 이나 Windows PowerShell ISE 도 아닙니다.
맨 위 최고의 매치 자리에 나온 Windows PowerShell 하나만 누르세요.
"관리자로 실행"은 누르지 않으셔도 됩니다. 그냥 이름을 바로 누르거나 오른쪽의 [열기]를 누르면 됩니다.

선택한 AI에 맞는 설치 경로

3단계는 클로드를 쓰는 분과 코덱스를 쓰는 분의 설치 방법이 다릅니다. 아래에서 하나를 고르시면 그 방법만 여기에 나타납니다. 나머지는 안 보이니 헷갈릴 일이 없습니다.

평소 쓰시는 것을 눌러 주세요

둘 중 뭘 쓰는지 모르시겠다면 — 이 챌린지 신청하실 때 결제하신 쪽입니다. 클로드(Claude)를 결제하셨으면 왼쪽, ChatGPT를 결제하고 코덱스를 쓰신다면 오른쪽입니다.
잘못 골라도 괜찮습니다. 위로 올라가 다시 누르면 바로 바뀝니다.

Claude와 필수 프로그램 설치

  2. 글자가 빠르게 지나가도 괜찮습니다. 20분 정도는 창을 닫지 말고 기다려 주세요.

    버튼 없이 막대만 차오르다 저절로 끝나기도 합니다 — 그것도 정상입니다.

  4. 마지막에 설치 결과 표가 나옵니다. 이게 보이면 설치가 끝난 겁니다.

· 셋팅코드 — 시작하는 날 메일로 드리는 파일입니다. 지금 없는 게 맞습니다.
· 분석 API 키 — 아래 8단계에서 준비합니다. 지금은 없어도 정상입니다.
· 수노 브라우저 — 곡을 만드는 날 사용하는 별도 Chrome 창입니다.

노란 글씨가 보여도 놀라지 마세요. 색이 아니라 글자를 보시면 됩니다.
「나중에」도 노란색으로 나오는데 그건 정상입니다. 다시 실행해야 하는 건 「확인 필요」·「재실행 필요」·「직접 설치」 이 세 가지입니다.
표 오른쪽 칸에 이 셋 중 하나라도 보이면, 그때만 파워셸 창(글자가 잔뜩 지나간 그 창)을 닫고 파워셸을 새로 열어 설치 한 줄을 한 번 더 실행해 주세요. 새로 깐 프로그램은 새 창에서만 인식됩니다. 셋 중 아무것도 안 보이면 창은 닫지 마세요. 표 아래에 「아직 확인이 필요한 것:」 이라는 줄도 함께 나옵니다.
이미 된 것은 건너뛰어 금방 끝납니다. 새로 깐 프로그램은 창을 다시 열어야 인식되는 경우가 많아서, 두 번째 실행에서 대부분 풀립니다.
두 번 해도 같은 자리에 남으면 어느 줄인지 먼저 보세요.
· 오늘 꼭 있어야 하는 것 둘 — Orca와 클로드코드. 이 둘 중 하나라도 「확인 필요」·「재실행 필요」·「직접 설치」로 남으면 4·5·6단계가 아예 시작되지 않습니다. 넘어가지 마시고 그 표를 사진 찍어 바로 참가방에 올려 주세요. 그날 안에 같이 풀어드립니다.
· 오늘은 아니어도 되는 것 — Git · Python · ffmpeg · Node.js · Chrome · 파이썬 패키지 · 수노 브라우저. 며칠 뒤 영상을 만들 때 쓰는 부품이라 오늘 노랗게 남아도 4·5·6단계는 그대로 하시면 됩니다. 다만 표는 한 장 찍어 참가방에 올려 주세요. 시작하는 날 AI가 채웁니다.
· 「셋팅코드」와 「분석 API 키」는 지금 「나중에」인 게 정상입니다. 셋팅코드는 시작하는 날 메일로 받아 설치 한 줄을 한 번 더 돌리면 들어갑니다. 분석 API 키는 아래 8단계에서 직접 만든 뒤 저장합니다. 8단계는 혼자 하셔도 되고, 거기 있는 글을 옆의 AI에게 붙여넣어 같이 하셔도 됩니다.
※ 표에 「Python」과 「파이썬 패키지」 두 줄이 따로 있습니다. 영어로 적힌 줄과 한글로 적힌 줄이라 글자 모양이 아예 다릅니다. 둘 다 오늘은 아니어도 되는 쪽입니다.
표에 「Orca — 직접 설치」라고 적힌 줄이 보이면 — 인터넷 창이 하나 저절로 열렸을 겁니다(영어 페이지입니다). 그 페이지에서 Windows라고 적힌 버튼을 눌러 파일을 받으세요. 받은 파일을 두 번 누르고 [다음] · [설치] · [마침]을 차례로 누르면 끝입니다. 그다음 파워셸로 돌아와 설치 한 줄을 한 번 더 실행해 주세요.
맨 끝에 「다 보셨으면 엔터를 눌러 주세요」가 뜹니다. 엔터를 한 번 눌러 주세요.
다시 실행할 게 없으면 창은 그대로 두세요. 아래 4단계와 8단계에서 이 창을 다시 씁니다.

YouTube 채널과 전화번호 인증 준비

맞춤 썸네일 사용에 필요한 기능을 활성화하려면 채널 전화번호 인증을 미리 마쳐야 합니다.

영상을 올릴 내 채널이 있어야 합니다. 할 일은 두 가지 — 채널 만들기와 전화번호 인증입니다.

① 채널 만들기 — 이미 채널이 있으면 건너뛰세요

  1. 브라우저에서 youtube.com에 들어가 오른쪽 위 동그란 프로필 사진을 누릅니다.
  2. 메뉴에 [내 채널]이 보이면 이미 채널이 있는 것입니다 — ②로 바로 가세요.
  3. [채널 만들기]가 보이면 그걸 누르고, 이름은 아무거나 적고 넘어가세요. 나중에 바꿀 수 있습니다.

② 전화번호 인증 — 주소 하나로 바로 갑니다

  1. 브라우저 주소창에 아래를 붙여넣고 Enter를 누르세요. 메뉴를 타고 들어갈 필요가 없습니다.
  2. 휴대폰 번호를 넣고 문자로 받기를 고른 뒤, 문자로 온 6자리 숫자를 넣으면 끝입니다.
youtube.com/verify
"이미 인증됨"이라고 나오면 예전에 해두신 것이니 그냥 넘어가시면 됩니다.
전화번호 인증은 꼭 해주세요. 이게 없으면 나중에 썸네일이 자동으로 안 붙습니다. 1분이면 끝나고, 지금 해두는 편이 훨씬 편합니다.

공개 채널 분석용 API 키 준비

이 키는 2일차에 참고 채널의 공개 통계를 읽는 데만 사용합니다.
내 채널에 접근하거나 영상을 대신 올리는 권한이 아닙니다. 영상 게시와 예약은 YouTube Studio에서 직접 진행합니다.

시작 전에 세 가지를 확인하세요.
· 전부 무료입니다. 카드 등록도 없습니다.
· 내 구글 계정 안에서만 만들어지는 것이고, 남에게 공개되지 않습니다.
· 키 문자열은 비밀번호처럼 취급하고 사진이나 채팅에 공개하지 않습니다.
이 단계는 Day 0 완료와 인증에 필요한 필수 단계입니다.
프로젝트 만들기 → API 사용 → 키 생성·제한의 세 화면으로 진행되며 약 5~10분이 걸립니다. 막히면 키 문자열을 가리고 현재 화면만 참가방에 올리세요.

손이 제일 적게 가는 길 — 옆에 있는 AI에게 시키세요

6단계에서 열어둔 Orca의 AI가 옆에 있습니다. 아래 글을 붙여넣으면 한 화면에 하나씩 알려주고, 내가 "됐어"라고 할 때까지 기다려 줍니다. 화면이 안내와 다르면 보이는 대로 말하면 거기에 맞춰 다시 알려줍니다.

공개 유튜브 채널 분석에 쓸 API 키를 만들려고 해. 나는 컴퓨터를 잘 몰라.
한 번에 화면 하나씩만 알려주고, 내가 "됐어"라고 하면 다음 화면을 알려줘.
버튼 이름은 화면에 보이는 글자 그대로 말해줘.

만들 것: console.cloud.google.com 에서
1) 새 프로젝트 (이름: 플리공장)
2) YouTube Data API v3 사용 설정
3) API 및 서비스 → 사용자 인증 정보에서 API 키 만들기 → YouTube Data API v3로 제한 → 복사
4) 키 문자열을 C:\플리공장\API키.txt에 저장

내가 지금 보는 화면을 설명하면 거기에 맞춰서 알려줘.
중간에 내가 뭘 잘못 눌렀는지 물어보면 되돌리는 법도 알려줘.

직접 진행하기 — 세 단계입니다

먼저 브라우저에서 아래 주소를 열고, 유튜브 채널이 있는 구글 계정으로 로그인해 주세요.

console.cloud.google.com

화면 1 — Google Cloud 프로젝트 만들기

  • 화면 맨 위 왼쪽, Google Cloud 글자 바로 옆에 둥근 알약 모양의 칸이 있습니다. 그게 프로젝트를 고르는 칸입니다. 누르세요.

YouTube Data API v3
✅ 버튼이 [사용] → [관리] 로 바뀌면 성공.

화면 3 — 채널 분석용 API 키 만들기

  • ≡ → API 및 서비스 → 사용자 인증 정보 로 갑니다.

  • 바로 만들어집니다. 나온 긴 글자를 복사해 두세요. (AIza 로 시작합니다)
  • [키 제한]을 누릅니다. 이 로컬 실습에서는 애플리케이션 제한은 없음으로 두고, API 제한 → 키 제한 → YouTube Data API v3만 선택해 저장합니다.
✅ 복사했으면 성공. 다음 단계에서 이 글자를 파일로 저장합니다.
API 키는 목록에서 다시 확인할 수 있습니다. 다만 키 문자열이 보이는 화면을 촬영하거나 채팅방에 공유하지 마세요.
API 키는 공개 채널의 조회수·길이·발행 요일을 읽는 번호표입니다. 2일차의 「이 채널 분석해줘」에만 사용하며, 내 채널의 영상·설정에는 접근하지 않습니다.

    3. [파일] → [저장]을 누르면 저장 창이 열립니다. 파일 이름 칸을 한 번 누르고 거기 있던 글자를 지운 뒤, 아래 주소를 통째로 붙여넣고 [저장]을 누르세요. 폴더를 찾아 들어가실 필요가 없습니다 — 5단계에서 쓰신 것과 같은 방법입니다
    C:\플리공장\API키.txt
    ✅ 메모장 창 맨 위에 「API키」라고 뜨면 저장된 겁니다. 이제 메모장은 닫으셔도 됩니다.

메모장에 붙여넣고 [파일] → [저장], 이름은 API키, 저장 위치는 C:\플리공장 이면 끝입니다.

Suno 계정 준비

인증 메일이 스팸함으로 들어가는 경우가 있으므로 수노 가입을 미리 완료해 두세요.

수노는 노래를 만들어 주는 사이트입니다. 며칠 뒤 내 곡을 만들 때 쓰는데, 가입만 오늘 해두면 그날 바로 시작할 수 있습니다.

  1. 브라우저에서 suno.com에 들어가 [Sign Up]으로 가입해 주세요. 구글 계정으로 가입하면 비밀번호를 새로 만들지 않아도 됩니다.
  2. 무료로 시작할 수 있습니다. 지금 결제하지 않으셔도 됩니다.
  3. 가입만 확인하고 창을 닫으세요. 곡은 나중에 만듭니다.
오늘은 무료로 가입만 하시면 됩니다. 무료 계정은 하루에 만들 수 있는 곡 수가 정해져 있습니다. 3일차까지는 무료로 충분합니다. 곡을 한두 개만 만드는 날이기 때문입니다.
다만 3일차와 5일차에는 곡을 여러 번 만들어 보게 되고, 무료로 만든 곡은 수노 규정상 돈 버는 용도로 쓰는 데 제한이 있습니다. 그래서 그때 유료로 올리는 분이 대부분입니다.
오늘은 결제하지 마세요. 얼마인지는 수노 화면에 그때그때 표시되는 값을 보시면 됩니다. 곡이 막히는 날 참가방에 올려 주시면 같이 보겠습니다. 미리 알려드리는 이유는, 그날 갑자기 알게 되는 게 제일 당황스럽기 때문입니다.
