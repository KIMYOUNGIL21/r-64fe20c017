먼저 컴퓨터부터
준비해둘게요

챌린지가 시작되기 전에 해두는 환경 세팅입니다. 오늘은 프로그램을 깔고 로그인만 합니다.
약 30~50분이고, 중간에 쉬었다 이어서 해도 괜찮습니다.

먼저, 내가 쓸 AI를 골라볼게요

아래에서 평소 사용하는 AI 이름 하나만 눌러 주세요. 누른 뒤에는 그 AI에 필요한 안내만 보이니 편하게 따라오시면 됩니다.

위의 두 버튼 중 하나를 누르면 다음 안내가 열립니다.

0

오늘 할 일은 이것뿐입니다

오늘의 목표는 딱 하나입니다 — Orca라는 창 안에서 내 AI가 열리게 만드는 것. 여기까지만 되면 오늘은 끝입니다.

  1. 영상 만들기는 오늘 안 합니다. 챌린지가 시작되면 그때 다음 안내를 드립니다.
  2. 오늘은 받으실 파일이 없습니다. 챌린지에 쓸 파일은 시작하는 날 따로 드립니다.
  3. Orca는 AI에게 일을 부탁하는 작업 창입니다. 여기서 한국어로 말하면 됩니다.
  4. Git, 파이썬, ffmpeg 같은 낯선 이름이 지나가도 괜찮습니다. 영상 공장에 들어갈 부품이고, 외우실 필요 없습니다.
용어를 외울 필요는 없습니다. 이 안내서에 보이는 버튼만 차례대로 눌러 주세요.
1

시작 전에 필요한 것

  • 인터넷이 연결된 내 윈도우 PC. 프로그램을 설치할 수 있는 본인 컴퓨터여야 합니다.
  • 클로드 또는 코덱스 유료 구독 계정. 둘 중 하나만 있으면 됩니다 (참가 조건입니다).
  • 로그인할 때 쓸 이메일과 비밀번호. 인증번호를 받을 휴대폰도 옆에 두세요.
  • 넉넉한 30~50분. 설치가 도는 동안은 기다리는 시간이 많습니다.
이 페이지는 설치할 윈도우 PC에서 열어 주세요. 휴대폰으로 보고 계시면, 그 PC에서 이 링크를 다시 열어야 복사 버튼을 쓸 수 있습니다.
2

파워셸 창을 열어볼게요

파워셸은 컴퓨터에게 설치를 부탁하는 창입니다. 파란색이나 검은색 화면이 열려도 놀라지 않으셔도 됩니다.

  1. 키보드 왼쪽 아래의 윈도우 모양 키를 한 번 눌러 주세요.
  2. 그대로 powershell을 영어로 입력해 주세요. 한글로 입력되면 한영 키를 누른 뒤 다시 적으면 됩니다.
  3. Windows PowerShell을 한 번 눌러 주세요.
  4. 파란색 또는 검은색 창이 열리면 잘하신 겁니다. 창은 그대로 두고 다음 단계로 가면 됩니다.
검색 결과가 여러 개여도 Windows PowerShell이라고 적힌 항목을 누르면 됩니다.
3

클로드와 필요한 프로그램을 한 번에 설치할게요

아래 버튼을 누른 뒤, 파워셸 창 안을 한 번 누르고 마우스 오른쪽 버튼을 눌러 주세요. 글이 붙으면 Enter를 한 번 누르면 됩니다.

$env:PLI_AI='claude'; irm https://raw.githubusercontent.com/KIMYOUNGIL21/r-64fe20c017/main/pli/setup.ps1 | iex
  1. 이 앱이 디바이스를 변경하도록 허용하시겠습니까라고 물으면 [예]를 눌러 주세요. 정상 과정입니다.
  2. 글자가 잠시 멈춘 것처럼 보여도 괜찮습니다. 20분 정도는 창을 닫지 말고 기다려 주세요.
  3. 중간에 Orca 설치 창이 열리면 [다음] → [설치] → [마침]을 눌러 주세요. 그래야 나머지가 이어집니다.
  4. 마지막에 설치 결과 표가 나옵니다. 이게 보이면 설치가 끝난 겁니다.
  5. 이어서 검은 로그인 창이 열립니다 — 다음 단계로 가세요.
이 한 줄이 Git · 파이썬 · ffmpeg · Node.js · 크롬 · 클로드코드 · Orca를 순서대로 설치합니다. 이미 깔려 있는 것은 건너뜁니다. 여러 번 실행해도 안전합니다.
표에 노란 글씨가 보이면 이 창을 닫고 설치 한 줄을 한 번 더 실행해 주세요. 이미 된 것은 건너뛰어 금방 끝납니다. 새 프로그램은 창을 다시 열어야 인식되는 경우가 많아, 두 번째 실행에서 대부분 해결됩니다.
표에 셋팅코드라는 줄이 보이고 "나중에"라고 적혀 있어도 정상입니다. 그 파일은 챌린지 시작하는 날 드립니다. 지금 없는 게 맞습니다.

이제 로그인만 하면 됩니다

앞 단계 마지막에 검은 창이 새로 열렸을 겁니다. 그 창에서 로그인해 주세요. 안내에 따라 브라우저가 열리면 평소 쓰는 계정으로 로그인하면 됩니다.

검은 창이 열리지 않았을 때만 아래를 복사해 파워셸에 붙여넣고 Enter를 눌러 주세요.

claude

검은 창이 열리지 않았을 때만 아래를 복사해 파워셸에 붙여넣고 Enter를 눌러 주세요.

codex login
로그인이 끝나면 그 검은 창은 닫아도 됩니다.
유료 구독이 되어 있는 계정으로 로그인해 주세요. 무료 계정으로 로그인하면 챌린지 중에 막힙니다.
5

Orca를 열고 공장 폴더를 골라볼게요

폴더는 이미 만들어져 있습니다. 앞 단계의 설치 한 줄이 C:\플리공장을 만들어 뒀습니다. 여기서는 그 폴더를 고르기만 하면 됩니다.

  1. 바탕화면 또는 시작 메뉴에서 Orca를 찾아 열어 주세요. 고래 모양 아이콘입니다.
  2. 처음 실행할 때 폴더 접근을 허용해 달라고 하면 [허용]을 눌러 주세요.
  3. 첫 화면의 Add Project 버튼을 눌러 주세요.
  4. 폴더 찾아보기를 눌러 주세요.
  5. 왼쪽의 내 PC → 로컬 디스크 C를 눌러 주세요.
  6. 거기 있는 플리공장 폴더를 한 번 누른 뒤 [폴더 선택] 또는 [열기]를 눌러 주세요.
조금 전에 로그인한 AI 계정을 가져오겠다고 나오면 [가져오기]를 눌러 주세요. 자연스러운 과정입니다.
플리공장 폴더가 안 보이면 앞의 설치 한 줄이 끝까지 못 간 것입니다. 파워셸에서 한 번 더 실행해 주세요.
6

Orca 안에서 AI를 열어볼게요

오늘의 마지막 단계입니다.

  1. 플리공장 폴더가 열린 Orca 화면에서 터미널 또는 새 터미널 버튼을 눌러 주세요. 아래쪽에 검은 창이 나오면 맞습니다.
  2. 검은 창 위쪽의 Agent, 에이전트, 또는 선택 상자를 눌러 주세요.
  3. Claude Code를 눌러 주세요.
  4. Codex를 눌러 주세요.
  5. 검은 창에 AI의 인사말과 입력하는 줄이 보이면 잘 된 겁니다.
선택 상자에 지금 고른 AI 이름이 보이지 않으면, 그 화면을 사진으로 남겨두고 참가방에 올려 주세요.
인사말이 보이면 오늘은 여기서 끝입니다. 아무것도 입력하지 않으셔도 됩니다.

□ Orca에서 플리공장 폴더가 열려 있습니다.
□ Orca 안에서 내 AI가 열리고 인사말이 보입니다.
참가방에 사진 한 장만 올려 주세요. Orca 안에서 AI 인사말이 보이는 화면이면 됩니다. 이걸로 환경 세팅 확인이 끝납니다.

다음은 무엇인가요?

챌린지가 시작되는 날 두 번째 안내서와 공장에 넣을 파일을 함께 드립니다. 그때 이런 것들을 합니다 — 공장 파일 넣기, 내 유튜브 연결하기, 첫 영상 만들어 올려보기.

그때까지는 아무것도 안 하셔도 됩니다. 오늘 깔아둔 것들은 그대로 두시면 됩니다.

중간에 멈춰도 괜찮아요

  • 어려운 말이 보이면 혼자 해결하려 애쓰지 않아도 됩니다. 멈춘 화면을 사진으로 한 장 남겨 주세요.
  • 몇 번째 단계에서 멈췄는지만 함께 적어 참가방에 올려 주세요. 당일 안에 같이 풀어드립니다.
  • 대부분의 문제는 설치 한 줄을 한 번 더 실행하면 해결됩니다. 여러 번 해도 안전합니다.
  • 사진을 보낼 일이 있다면 비밀번호, 인증번호, 카드번호는 보이지 않게 가려 주세요.
  • 답답해도 프로그램을 지우거나 다른 설치를 하기보다는, 잠시 그대로 두는 편이 좋습니다.
