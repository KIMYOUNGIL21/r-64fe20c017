오늘 할 일을 먼저 볼게요

크게 두 가지입니다 — ① 맥에 프로그램 깔기 ② 필요한 계정 만들어두기. 그게 전부입니다.

  1. 영상 만들기는 오늘 안 합니다. 시작하는 날 다음 안내서를 드립니다.
  2. 오늘은 받으실 파일이 없습니다. 챌린지에 쓸 파일은 시작하는 날 따로 드립니다.
  3. Orca는 AI에게 일을 부탁하는 작업 창입니다. 여기서 한국어로 말하면 됩니다.
  4. Homebrew, 파이썬, ffmpeg 같은 낯선 이름이 지나가도 괜찮습니다. 영상 공장에 들어갈 부품이고, 외우실 필요 없습니다.
이 안내서는 맥 전용입니다. 코덱스(ChatGPT) 사용자 기준으로 적혀 있습니다.
각 단계 아래에 체크 칸이 있습니다. 끝낼 때마다 눌러 주세요. 맨 위 막대가 차오르고, 맥을 껐다 켜도 체크한 것은 그대로 남습니다. 전부 채우면 마지막에 참가방에 올릴 문구가 나옵니다.

시작 전에 필요한 것

  • 인터넷이 연결된 내 맥. 프로그램을 설치할 수 있는 본인 컴퓨터여야 합니다.
  • 코덱스를 쓸 수 있는 ChatGPT 유료 계정 (참가 조건입니다).
  • 구글 계정. 유튜브를 쓸 계정입니다. 없으면 지금 하나 만들어 두세요.
  • 맥 로그인 비밀번호. 설치 도중 한 번 물어봅니다. 맥을 켤 때 넣는 그 비밀번호입니다.
  • 로그인할 때 쓸 이메일과 비밀번호, 인증번호를 받을 휴대폰.
  • 넉넉한 1시간~1시간 30분. 설치가 도는 동안은 기다리는 시간이 많습니다.
이 페이지는 설치할 맥에서 열어 주세요. 휴대폰으로 보고 계시면, 그 맥에서 이 링크를 다시 열어야 복사 버튼을 쓸 수 있습니다.

터미널을 열어볼게요

터미널은 컴퓨터에게 설치를 부탁하는 창입니다. 흰색이나 검은색 화면이 열려도 놀라지 않으셔도 됩니다.

  1. 키보드에서 ⌘ + 스페이스를 함께 눌러 주세요. 화면 가운데에 검색창이 뜹니다.
  2. 터미널이라고 입력해 주세요. (영어로 Terminal이라고 쳐도 됩니다.)
  3. 맨 위에 나온 터미널을 Enter로 열어 주세요.
  4. 글자만 있는 창이 열리면 잘하신 겁니다. 창은 그대로 두고 다음 단계로 가면 됩니다.

코덱스와 필요한 프로그램을 한 번에 설치할게요

아래 버튼을 누른 뒤, 터미널 창 안을 한 번 누르고 ⌘ + V로 붙여넣어 주세요. 그리고 Enter를 한 번 누르면 됩니다.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/KIMYOUNGIL21/r-64fe20c017/main/pli/setup-mac.sh)"
  1. 설치 도중 Password: 라고 나오면 맥 로그인 비밀번호를 치고 Enter를 누르세요.
  2. 글자가 잠시 멈춘 것처럼 보여도 괜찮습니다. 30분 정도는 창을 닫지 말고 기다려 주세요.
  3. 마지막에 설치 결과 표가 나옵니다. 이게 보이면 설치가 끝난 겁니다.
  4. 이어서 코덱스 로그인이 시작되고 브라우저가 열립니다 — 다음 단계로 가세요.
비밀번호를 쳐도 화면에 아무것도 안 보입니다. 별표도, 점도 안 나옵니다. 고장이 아니라 맥의 원래 방식입니다. 그냥 치고 Enter를 누르면 됩니다.
이 한 줄이 Homebrew · Git · 파이썬 · ffmpeg · Node.js · 크롬 · 코덱스 · Orca를 순서대로 설치합니다. 이미 깔려 있는 것은 건너뜁니다. 여러 번 실행해도 안전합니다.
"나중에" 라고 적힌 줄이 보여도 전부 정상입니다. 몇 개든 상관없습니다.
· 셋팅코드 — 시작하는 날 메일로 드리는 파일입니다. 지금 없는 게 맞습니다.
· 구글 열쇠 — 아래 8단계에서 직접 만드실 것입니다. 지금은 없는 게 맞습니다.
· 파이썬 패키지 · 수노 브라우저 — 이것들이 "나중에"로 뜨는 경우도 있는데, 시작하는 날 AI가 알아서 채웁니다.
줄 앞에 노란 [확인] 이 붙은 게 있으면 터미널을 닫고 설치 한 줄을 한 번 더 실행해 주세요. (잘된 줄에는 초록 [OK] 가 붙습니다.)
이미 된 것은 건너뛰어 금방 끝납니다. 새로 깐 프로그램은 창을 다시 열어야 인식되는 경우가 많아서, 두 번째 실행에서 대부분 풀립니다.

브라우저가 열리지 않았을 때만 아래를 복사해 터미널에 붙여넣고 Enter를 눌러 주세요.

codex login
이번에 처음 결제하신 분은 여기를 꼭 읽어 주세요.
로그인은 결제하신 바로 그 계정으로 해야 합니다. 평소 쓰던 다른 이메일로 로그인하면 무료 계정으로 들어가서 챌린지 중에 막힙니다.
헷갈리시면 브라우저에서 chatgpt.com에 들어가 보세요. 거기 로그인돼 있는 계정이 결제하신 계정입니다.

Orca를 열고 공장 폴더를 골라볼게요

폴더는 이미 만들어져 있습니다. 앞 단계의 설치 한 줄이 내 사용자 폴더 안에 플리공장을 만들어 뒀습니다. 여기서는 그 폴더를 고르기만 하면 됩니다.

먼저 알아두실 것 — 이 프로그램은 버튼이 영어입니다. 어떤 영어 글자를 눌러야 하는지 아래에 그대로 적어뒀으니 그것만 찾으시면 됩니다.
  1. 런치패드 또는 응용 프로그램 폴더에서 Orca를 찾아 열어 주세요. 고래 모양 아이콘입니다.
  2. 처음 열 때 "인터넷에서 다운로드한 앱입니다"라고 물으면 [열기]를 눌러 주세요.
  3. 폴더 접근을 허용해 달라고 하면 [허용]을 눌러 주세요.
  4. 첫 화면에서 Add Project (영어로 이렇게 써 있습니다)를 눌러 주세요.
  5. 폴더 찾아보기를 눌러 주세요. 폴더를 고르는 창이 열립니다.
  6. 폴더를 찾아 들어가지 마세요. 그 창이 떠 있는 상태에서 ⌘ + Shift + G를 함께 누르면 주소를 적는 작은 칸이 나옵니다. 아래 버튼으로 주소를 복사해 그 칸에 ⌘ + V로 붙여넣고 Enter를 누르면 한 번에 열립니다.
  7. 그 상태에서 [열기] 또는 [폴더 선택]을 눌러 주세요.
~/플리공장
작은 칸이 안 나오면 이렇게 찾아가셔도 됩니다 — 왼쪽에서 내 이름이 적힌 집 모양 폴더를 누르고, 거기 있는 플리공장 폴더를 한 번 누른 뒤 [열기] 또는 [폴더 선택].
조금 전에 로그인한 코덱스 계정을 가져오겠다고 나오면 [가져오기]를 눌러 주세요. 자연스러운 과정입니다.
플리공장 폴더가 안 보이면 앞의 설치 한 줄이 끝까지 못 간 것입니다. 터미널에서 한 번 더 실행해 주세요.
폴더를 열어 봤는데 거의 비어 있어도 정상입니다. 지금은 빈 방 세 개(재료·완성·기록)만 있습니다. 공장 파일은 시작하는 날 들어갑니다.
Orca가 "손상되었기 때문에 열 수 없습니다"라고 나오면 설치 한 줄을 한 번 더 실행해 주세요. 맥이 인터넷에서 받은 앱을 막아둔 것이고, 설치 한 줄이 그 표시를 떼어냅니다.

Orca 안에서 코덱스를 열어볼게요

맥 준비는 여기까지입니다. 이제부터는 계정 준비입니다.

  1. 여기서 말하는 「터미널」은 2단계에서 여신 그 창이 아닙니다. Orca 안쪽에 생기는 칸입니다. 맥의 터미널 앱은 지금 닫으셔도 됩니다.
    플리공장 폴더가 열린 Orca 화면에서 터미널 또는 새 터미널 버튼을 눌러 주세요.
    (터미널 = AI와 대화하는 검은 칸입니다. 화면 아래쪽에 검은 칸이 생기면 맞습니다.)
  2. 그 검은 칸 위쪽에 Agent 또는 에이전트라고 적힌 선택 상자가 있습니다. 눌러 주세요.
    (여기가 어떤 AI를 쓸지 고르는 곳입니다.)
  3. 목록에서 Codex를 눌러 주세요.
  4. 검은 칸에 코덱스의 인사말과 글자를 입력하는 줄이 보이면 잘 된 겁니다.
처음 켜면 질문이 몇 개 나옵니다. 영어일 수 있습니다 — 놀라지 마세요.
대부분 화살표 키(↑↓)로 고르고 Enter로 답합니다. 마우스가 아니라 키보드를 씁니다.

· 화면 색을 고르라는 질문 → 아무거나 고르고 Enter. 나중에 바꿀 수 있습니다.
· 이 폴더를 믿어도 되냐고 묻는 질문 (trust · yes 같은 단어가 보입니다) → 반드시 "예"에 해당하는 쪽을 고르세요. 여기서 "아니오"를 고르면 진행이 안 됩니다.
· 로그인하라는 질문이 또 나오면 → 4단계에서 하신 그 계정으로 하시면 됩니다.

질문이 다 지나가면 인사말이 나옵니다. 모르는 질문이 나오면 그 화면을 사진 찍어 참가방에 올려 주세요. 바로 답해 드립니다.
선택 상자에 Codex가 아예 보이지 않으면, 그 화면을 사진으로 남겨 참가방에 올려 주세요.
인사말이 보이면 맥 준비 끝! 아무것도 입력하지 않으셔도 됩니다. 이 화면은 사진으로 찍어두세요 — 마지막에 참가방에 올릴 인증 사진 두 장 중 하나입니다.

유튜브 채널을 만들고 전화번호 인증까지 해둘게요

영상을 올릴 내 채널이 있어야 합니다. 할 일은 두 가지 — 채널 만들기와 전화번호 인증입니다.

① 채널 만들기 — 이미 채널이 있으면 건너뛰세요

  1. 브라우저에서 youtube.com에 들어가 오른쪽 위 동그란 프로필 사진을 누릅니다.
  2. 메뉴에 [내 채널]이 보이면 이미 채널이 있는 것입니다 — ②로 바로 가세요.
  3. [채널 만들기]가 보이면 그걸 누르고, 이름은 아무거나 적고 넘어가세요. 나중에 바꿀 수 있습니다.

② 전화번호 인증 — 주소 하나로 바로 갑니다

  1. 브라우저 주소창에 아래를 붙여넣고 Enter를 누르세요. 메뉴를 타고 들어갈 필요가 없습니다.
  2. 휴대폰 번호를 넣고 문자로 받기를 고른 뒤, 문자로 온 6자리 숫자를 넣으면 끝입니다.
youtube.com/verify
"이미 인증됨"이라고 나오면 예전에 해두신 것이니 그냥 넘어가시면 됩니다.
전화번호 인증은 꼭 해주세요. 이게 없으면 나중에 썸네일이 자동으로 안 붙습니다. 1분이면 끝나고, 지금 해두는 편이 훨씬 편합니다.

유튜브에 자동으로 올릴 "열쇠"를 만들어둘게요

저도 이 화면을 처음 열었을 때 20분을 헤맸습니다. 어려워서가 아니었습니다. 구글이 메뉴 이름을 최근에 바꿔 놓아서, 안내서와 실제 화면이 안 맞았기 때문입니다. 그래서 이번엔 바뀐 이름과 옛 이름을 둘 다 적어 뒀습니다. 화면에 보이는 쪽을 누르시면 됩니다.

먼저 무엇을 하는 건지부터 말씀드릴게요.
내 컴퓨터의 공장이 내 유튜브에 영상을 대신 올리려면, 구글에게 "이 프로그램은 제가 쓰는 게 맞습니다"라고 알려줘야 합니다. 그 절차를 마치면 열쇠 파일이 하나 내려받아집니다. 그 파일을 공장에 넣어두면 끝입니다.

세 가지만 먼저 안심하세요.
· 전부 무료입니다. 카드 등록도 없습니다.
· 내 구글 계정 안에서만 만들어지는 것이고, 남에게 공개되지 않습니다.
· 잘못 눌러도 아무것도 망가지지 않습니다. 마음에 안 들면 지우고 다시 만들면 됩니다.
여기가 오늘 제일 어렵습니다. 그래서 미리 말씀드립니다.
화면이 여섯 번 바뀝니다. 한 화면에서 하는 일은 딱 하나씩이라 그것만 보시면 됩니다. 15~25분 걸립니다.

막히면 그냥 멈추셔도 됩니다. 8번은 시작하는 날 같이 해도 되는 단계입니다. 나머지(9번 수노)까지만 끝내고 멈춘 화면을 사진 찍어 참가방에 올려 주세요. 여기서 포기하지만 않으시면 됩니다.
구글이 최근에 메뉴 이름을 바꿨습니다. 화면에 따라 예전 이름이 보일 수도 있어서, 아래에 두 이름을 같이 적어뒀습니다. 둘 중 보이는 쪽을 누르시면 됩니다.

6단계에서 열어둔 Orca의 코덱스가 옆에 있습니다. 아래 글을 붙여넣으면 한 화면에 하나씩 알려주고, 내가 "됐어"라고 할 때까지 기다려 줍니다. 화면이 안내와 다르면 보이는 대로 말하면 거기에 맞춰 다시 알려줍니다.

유튜브 자동 업로드에 쓸 구글 열쇠를 만들려고 해. 나는 컴퓨터를 잘 몰라.
한 번에 화면 하나씩만 알려주고, 내가 "됐어"라고 하면 다음 화면을 알려줘.
버튼 이름은 화면에 보이는 글자 그대로 말해줘.

만들 것: console.cloud.google.com 에서
1) 새 프로젝트 (이름: 플리공장)
2) YouTube Data API v3 사용 설정
3) 메뉴 ≡ → API 및 서비스 → OAuth 동의 화면 → 외부 선택 → 앱 이름과 이메일 등록
4) 이어지는 테스트 사용자 화면에서 내 이메일 추가
5) API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 ID → 데스크톱 앱 → JSON 다운로드
6) 같은 화면에서 API 키 하나 만들어서 복사

계정에 따라 메뉴 이름이 다를 수 있어. 브랜딩·대상·클라이언트로 나뉘어 보이면
브랜딩=앱 이름, 대상=외부와 테스트 사용자, 클라이언트=OAuth 클라이언트 만들기야.
내가 지금 보는 화면을 설명하면 거기에 맞춰서 알려줘.
중간에 내가 뭘 잘못 눌렀는지 물어보면 되돌리는 법도 알려줘.

직접 하실 분 — 화면 여섯 번입니다

먼저 브라우저에서 아래 주소를 열고, 유튜브 채널이 있는 구글 계정으로 로그인해 주세요.

console.cloud.google.com

화면 1 — 내 서랍 하나 만들기 (프로젝트)

  • 화면 맨 위 왼쪽, Google Cloud 글자 바로 옆에 둥근 알약 모양의 칸이 있습니다. 그게 프로젝트를 고르는 칸입니다. 누르세요.
  • 리소스 선택 창이 뜹니다. 오른쪽 위의 파란 글씨 [새 프로젝트]를 누르세요.
  • 이름 칸에 플리공장이라고 적고 [만들기].
  • 잠시 뒤 만들어집니다. 맨 위 알약 칸에 "플리공장"이 보이는지 확인하세요.
✅ 맨 위에 "플리공장"이 보이면 성공. 앞으로 하는 일은 전부 이 서랍 안에 담깁니다.
여기서 자주 헤맵니다 — 만들고 나서 맨 위 칸이 다른 이름이면, 그 칸을 다시 눌러 목록에서 플리공장을 골라 주세요. 서랍이 바뀌면 뒤 단계가 엉뚱한 곳에 만들어집니다.

화면 2 — 유튜브 문 열기 (API 사용 설정)

  • 화면 맨 위 가운데 검색창에 아래를 붙여넣고 Enter.
  • 검색 결과에서 YouTube Data API v3 를 누르면 소개 화면이 나옵니다.
  • 파란 [사용] 버튼을 누르세요. (영어면 ENABLE)
YouTube Data API v3
✅ 버튼이 [사용] → [관리] 로 바뀌면 성공.

화면 3 — 동의 화면 시작하기

왼쪽 메뉴부터 엽니다. 화면 맨 왼쪽 위의 줄 세 개(≡)를 누르고 API 및 서비스를 누르세요.
누르면 화면 이름이 바뀝니다 — 잘못 온 게 아닙니다.
OAuth 동의 화면을 누르면 「Google 인증 플랫폼」 이라는 곳으로 넘어가고, 왼쪽 메뉴도 개요 · 브랜딩 · 대상 · 클라이언트 로 바뀝니다. 맞게 오신 겁니다. 여기서 계속하시면 됩니다.
  • 가운데 파란 [시작하기] 버튼을 누르세요.
  • 앱 이름에 플리공장, 사용자 지원 이메일은 내 이메일을 고릅니다.
  • 사용자 유형(대상)을 물으면 외부 (영어면 External)를 고르세요.
  • 연락처 이메일에도 같은 이메일을 넣습니다.
  • 맨 아래 동의 체크를 하고 [만들기] 또는 [계속].
칸 이름이 조금 다르게 보여도 괜찮습니다. 채울 것은 결국 앱 이름과 내 이메일 둘뿐입니다. 나머지는 비워 두셔도 됩니다. 헷갈리면 그 화면을 사진 찍어 AI에게 보여주고 물어보세요.
✅ 왼쪽 메뉴에 [대상] 이 눌러지면 성공. 다음 화면으로 갑니다.

화면 4 — 내 이메일을 테스트 사용자로 등록

  • 왼쪽 메뉴에서 대상 (영어면 Audience)을 누르세요.
  • 화면을 아래로 내리면 테스트 사용자 칸이 있습니다.
  • [사용자 추가] 또는 [+ ADD USERS] → 내 이메일 주소를 적고 [저장].
이 화면을 건너뛰면 나중에 반드시 막힙니다. 여기에 내 이메일을 넣지 않으면 마지막 연결 단계에서 "이 앱은 확인되지 않았습니다"에서 더 진행이 안 됩니다. 지나쳤다면 언제든 대상으로 돌아와 넣으시면 됩니다.
✅ 테스트 사용자 목록에 내 이메일이 보이면 성공.

화면 5 — 열쇠 만들기 (가장 중요)

  • 왼쪽 메뉴에서 클라이언트 (영어면 Clients)를 누르세요.
    또는 ≡ → API 및 서비스 → 사용자 인증 정보 로 가도 같은 곳입니다.
  • 위쪽 [+ 클라이언트 만들기] 또는 [+ 사용자 인증 정보 만들기] → [OAuth 클라이언트 ID]를 누르세요.
  • 애플리케이션 유형에서 데스크톱 앱을 고르세요.
    (웹 애플리케이션이 아닙니다. 꼭 데스크톱 앱입니다.)
  • 이름은 그대로 두고 [만들기].
  • 창이 뜨면 [JSON 다운로드]를 누르세요. 이게 열쇠 파일입니다.
다운로드 창을 그냥 닫아 버렸어도 괜찮습니다. 목록에 방금 만든 것이 보일 겁니다. 그 줄 오른쪽의 아래 화살표(↓) 모양을 누르면 다시 받을 수 있습니다.
✅ 다운로드 폴더에 client_secret_…json 이라는 긴 이름의 파일이 생기면 성공.
다운로드 폴더는 인터넷에서 받은 파일이 저절로 들어가는 곳입니다. Finder(웃는 얼굴 아이콘)를 열면 왼쪽에 「다운로드」가 있습니다.
이름을 바꾸거나 옮기지 마세요. 그대로 두시면 됩니다.

화면 6 — API 키 하나 더 (채널 분석에 씁니다)

  • ≡ → API 및 서비스 → 사용자 인증 정보 로 갑니다.
  • [+ 사용자 인증 정보 만들기] → 이번엔 [API 키] (위 사진의 맨 윗줄)를 누르세요.
  • 바로 만들어집니다. 나온 긴 글자를 복사해 두세요. (AIza 로 시작합니다)
  • 창에 [키 제한] 같은 버튼이 보여도 누르지 않으셔도 됩니다. [닫기]를 누르세요.
✅ 복사했으면 성공. 다음 단계에서 이 글자를 파일로 저장합니다.
복사한 걸 잃어버려도 괜찮습니다. 목록에 만들어진 키가 남아 있어서, 그 줄을 눌러 언제든 다시 복사할 수 있습니다.

마지막 — 받은 열쇠를 제자리에 넣기

  1. 터미널에서 3단계의 설치 한 줄을 한 번 더 실행해 주세요. 다운로드 폴더에서 열쇠 파일을 알아서 찾아 공장에 넣어 줍니다.
    (터미널을 닫으셨으면 2단계처럼 ⌘+스페이스로 다시 열고, 3단계의 복사 버튼을 다시 쓰시면 됩니다.)
  2. 복사해둔 API 키를 파일 하나에 저장해 둡니다.
    1. ⌘+스페이스를 누르고 텍스트 편집이라고 입력해 여세요. 새 문서가 안 열리면 [파일] → [새로 만들기]
    2. 그 창 안을 한 번 누르고 ⌘+V로 붙여넣습니다. AIza로 시작하는 긴 글자가 보이면 맞습니다
    3. [파일] → [저장], 이름은 API키, 저장 위치는 플리공장 폴더
이름도 형식도 신경 쓰지 않으셔도 됩니다.
붙여넣고 [파일] → [저장], 이름은 API키, 저장 위치는 플리공장 폴더면 끝입니다.
공장은 그 폴더에서 이름에 「키」가 들어간 글 파일을 전부 열어보고 찾아냅니다. API키.txt든 API키.rtf든 내API키.txt든 다 찾습니다.
✅ 설치 결과 표에 "구글 열쇠 — 방금 넣음"이 보이면 8번 완료입니다.
이때 로그인 안내가 다시 떠도 놀라지 마세요. 설치 한 줄은 실행할 때마다 로그인을 한 번씩 확인합니다. 이미 로그인돼 있으면 그냥 넘어가시면 됩니다.
시작하는 날엔 이 고생을 다시 하지 않습니다. Orca에 "유튜브 연결해줘" 한 마디만 하면, 브라우저에서 [허용] 한 번 누르는 걸로 끝납니다. 오늘 열쇠를 만들어뒀기 때문입니다.
"확인되지 않은 앱"이라는 무서운 경고가 나오면 — [고급] → [이동]을 누르시면 됩니다. 내가 방금 만든 내 앱이라 안전합니다. 구글이 모든 새 앱에 붙이는 문구입니다.

무료 플랜은 하루에 만들 수 있는 곡 수에 한도가 있습니다. 마음에 드는 곡이 잘 안 나오면 그날 유료로 올리는 분도 있는데, 지금 정하실 필요는 없습니다.
