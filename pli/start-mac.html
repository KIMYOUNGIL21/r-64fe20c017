맥과 계정을 준비합니다

챌린지가 시작되기 전에 맥과 계정을 전부 준비합니다.
오늘 다 해두면 시작하는 날은 아주 가볍습니다. 약 1시간~1시간 30분, 중간에 쉬었다 이어서 해도 됩니다.

결제한 서비스 하나를 고르면 아래의 설치·로그인·Orca 안내가 그 이름에 맞게 바뀝니다.

먼저 위의 두 버튼 중 하나를 선택하세요.

오늘의 목표와 범위

크게 두 가지입니다 — ① 맥에 프로그램 깔기 ② 필요한 계정 만들어두기. 그게 전부입니다.

  1. 영상 만들기는 오늘 안 합니다. 시작하는 날 다음 안내서를 드립니다.
  2. 오늘은 받으실 파일이 없습니다. 챌린지에 쓸 파일은 시작하는 날 따로 드립니다.
  3. Orca는 AI에게 일을 부탁하는 작업 창입니다. 여기서 한국어로 말하면 됩니다.
  4. Homebrew, 파이썬, ffmpeg 같은 낯선 이름이 지나가도 괜찮습니다. 영상 공장에 들어갈 부품이고, 외우실 필요 없습니다.
이 안내서는 맥 전용입니다. 위에서 선택한 클로드 또는 코덱스 기준으로 읽으시면 됩니다.
각 단계 아래에 체크 칸이 있습니다. 끝낼 때마다 눌러 주세요. 맨 위 막대가 차오르고, 맥을 껐다 켜도 체크한 것은 그대로 남습니다. 전부 채우면 마지막에 참가방에 올릴 문구가 나옵니다.
1

준비물과 예상 시간

  • 인터넷이 연결된 내 맥. 프로그램을 설치할 수 있는 본인 컴퓨터여야 합니다.
  • 클로드 또는 코덱스를 사용할 수 있는 유료 계정 (둘 중 하나가 참가 조건입니다).
  • 구글 계정. 유튜브를 쓸 계정입니다. 없으면 지금 하나 만들어 두세요.
  • 맥 로그인 비밀번호. 설치 도중 한 번 물어봅니다. 맥을 켤 때 넣는 그 비밀번호입니다.
  • 로그인할 때 쓸 이메일과 비밀번호, 인증번호를 받을 휴대폰.
  • 넉넉한 1시간~1시간 30분. 설치가 도는 동안은 기다리는 시간이 많습니다.
이 페이지는 설치할 맥에서 열어 주세요. 휴대폰으로 보고 계시면, 그 맥에서 이 링크를 다시 열어야 복사 버튼을 쓸 수 있습니다.

터미널 열기

터미널은 컴퓨터에게 설치를 부탁하는 창입니다. 흰색이나 검은색 화면이 열려도 놀라지 않으셔도 됩니다.

  1. 키보드에서 ⌘ + 스페이스를 함께 눌러 주세요. 화면 가운데에 검색창이 뜹니다.
  2. 터미널이라고 입력해 주세요. (영어로 Terminal이라고 쳐도 됩니다.)
  3. 맨 위에 나온 터미널을 Enter로 열어 주세요.
  4. 글자만 있는 창이 열리면 잘하신 겁니다. 창은 그대로 두고 다음 단계로 가면 됩니다.

AI와 필수 프로그램 설치

아래 버튼을 누른 뒤, 터미널 창 안을 한 번 누르고 ⌘ + V로 붙여넣어 주세요. 그리고 Enter를 한 번 누르면 됩니다.

아래 글은 읽지 않으셔도 됩니다. 영어와 기호가 잔뜩 섞여 있는데 신경 쓰지 마세요. 복사 버튼만 누르시면 됩니다. 사람이 아니라 컴퓨터가 읽을 글입니다.
먼저 페이지 위에서 사용할 AI를 선택하세요.
  1. 설치 도중 Password: 라고 나오면 맥 로그인 비밀번호를 치고 Enter를 누르세요.
  2. 글자가 잠시 멈춘 것처럼 보여도 괜찮습니다. 30분 정도는 창을 닫지 말고 기다려 주세요.
  3. 마지막에 설치 결과 목록이 나옵니다. 이게 보이면 설치가 끝난 겁니다.
  4. 이어서 AI 로그인이 시작됩니다. 화면 안내에 따라 다음 단계로 가세요.
비밀번호를 쳐도 화면에 아무것도 안 보입니다. 별표도, 점도 안 나옵니다. 고장이 아니라 맥의 원래 방식입니다.
입력한 뒤 Enter를 누르세요.
이 한 줄이 Homebrew · Git · 파이썬 · ffmpeg · Node.js · 크롬 · AI · Orca를 순서대로 설치합니다. 이미 깔려 있는 것은 건너뜁니다. 여러 번 실행해도 안전합니다.
"나중에"라고 적힌 줄이 보여도 정상입니다.
· 셋팅코드 — 시작하는 날 메일로 드리는 파일입니다. 지금 없는 게 맞습니다.
· 분석 API 키 — 아래 8단계에서 준비합니다. 지금은 없어도 정상입니다.
· 수노 브라우저 — 곡을 만드는 날 사용하는 별도 Chrome 창입니다.

초록 [OK] — 다 된 것입니다. 「나중에」도 초록 [OK]로 나옵니다. 그것도 정상입니다.
노란 [확인] — 이게 붙은 줄이 하나라도 있으면, 터미널 창을 닫고 설치 한 줄을 한 번 더 실행해 주세요.
이미 된 것은 건너뛰어 금방 끝납니다. 새로 깐 프로그램은 창을 다시 열어야 인식되는 경우가 많아, 두 번째 실행에서 대부분 풀립니다.
두 번 해도 같은 자리에 남으면 어느 줄인지 먼저 보세요.

· 「셋팅코드」와 「분석 API 키」는 지금 「나중에」인 게 정상입니다. 셋팅코드는 시작하는 날 메일로 받아 설치 한 줄을 한 번 더 돌리면 들어갑니다. 분석 API 키는 아래 8단계에서 직접 만든 뒤 저장합니다. 8단계는 혼자 하셔도 되고, 거기 있는 글을 옆의 AI에게 붙여넣어 같이 하셔도 됩니다.

AI 로그인

앞 단계 마지막에 로그인 안내가 나옵니다. 선택한 서비스의 유료 구독 계정으로 로그인해 주세요.

브라우저가 열리지 않았을 때만 아래를 복사해 터미널에 붙여넣고 Enter를 눌러 주세요.

먼저 페이지 위에서 사용할 AI를 선택하세요.
이번에 처음 결제하신 분은 여기를 꼭 읽어 주세요.
로그인은 결제하신 바로 그 계정으로 해야 합니다. 평소 쓰던 다른 이메일로 로그인하면 무료 계정으로 들어가서 챌린지 중에 막힙니다.
헷갈리면 선택한 서비스의 웹사이트에서 현재 로그인 계정과 구독 상태를 먼저 확인하세요.
이런 순서로 흘러갑니다.
① 터미널에 안내가 뜹니다 → ② 브라우저가 저절로 열립니다 → ③ 브라우저에서 로그인하고 [허용] 같은 버튼을 누릅니다 → ④ 다시 터미널로 돌아옵니다.
브라우저가 안 열리면 터미널에 주소가 하나 뜹니다. 그 주소를 복사해 브라우저에 붙여넣으면 됩니다.
터미널에 로그인 완료 표시가 나오면 끝입니다. 그 창은 닫아도 됩니다.

Orca에서 플리공장 폴더 열기

폴더는 이미 만들어져 있습니다. 앞 단계의 설치 한 줄이 내 사용자 폴더 안에 플리공장을 만들어 뒀습니다. 여기서는 그 폴더를 고르기만 하면 됩니다.

먼저 알아두실 것 — 이 프로그램은 버튼이 영어입니다. 어떤 영어 글자를 눌러야 하는지 아래에 그대로 적어뒀으니 그것만 찾으시면 됩니다.
  1. 런치패드 또는 응용 프로그램 폴더에서 Orca를 찾아 열어 주세요. 고래 모양 아이콘입니다.
  2. 처음 열 때 "인터넷에서 다운로드한 앱입니다"라고 물으면 [열기]를 눌러 주세요.
  3. 폴더 접근을 허용해 달라고 하면 [허용]을 눌러 주세요.
  4. 첫 화면에서 Add Project (영어로 이렇게 써 있습니다)를 눌러 주세요.
  5. 폴더 찾아보기를 눌러 주세요. 폴더를 고르는 창이 열립니다.
  6. 폴더를 찾아 들어가지 마세요. 그 창이 떠 있는 상태에서 ⌘ + Shift + G를 함께 누르면 주소를 적는 작은 칸이 나옵니다. 아래 버튼으로 주소를 복사해 그 칸에 ⌘ + V로 붙여넣고 Enter를 누르면 한 번에 열립니다.
  7. 그 상태에서 [열기] 또는 [폴더 선택]을 눌러 주세요.
~/플리공장
작은 칸이 안 나오면 이렇게 찾아가셔도 됩니다 — 왼쪽에서 내 이름이 적힌 집 모양 폴더를 누르고, 거기 있는 플리공장 폴더를 한 번 누른 뒤 [열기] 또는 [폴더 선택].
조금 전에 로그인한 AI 계정을 가져오겠다고 나오면 [가져오기]를 눌러 주세요.
플리공장 폴더가 안 보이면 앞의 설치 한 줄이 끝까지 못 간 것입니다. 터미널에서 한 번 더 실행해 주세요.
폴더를 열어 봤는데 거의 비어 있어도 정상입니다. 지금은 빈 방 세 개(재료·완성·기록)만 있습니다. 공장 파일은 시작하는 날 들어갑니다.
Orca가 "손상되었기 때문에 열 수 없습니다"라고 나오면 실행을 반복하거나 macOS 보안을 우회하지 마세요.
Orca 공식 설치 안내에서 현재 macOS용 설치 파일을 다시 받은 뒤에도 같으면, 오류 화면과 맥 종류를 참가방에 올려 주세요.

Orca에서 AI 실행 확인

맥 준비는 여기까지입니다. 이제부터는 계정 준비입니다.

  1. 여기서 말하는 「터미널」은 2단계에서 여신 그 창이 아닙니다. Orca 안쪽에 생기는 칸입니다. 맥의 터미널 앱은 지금 닫으셔도 됩니다.
    플리공장 폴더가 열린 Orca 화면에서 터미널 또는 새 터미널 버튼을 눌러 주세요.
    (터미널 = AI와 대화하는 검은 칸입니다. 화면 아래쪽에 검은 칸이 생기면 맞습니다.)
  2. 그 검은 칸 위쪽에 Agent 또는 에이전트라고 적힌 선택 상자가 있습니다. 눌러 주세요.
    (여기가 어떤 AI를 쓸지 고르는 곳입니다.)
  3. 목록에서 AI를 눌러 주세요.
  4. 검은 칸에 AI의 인사말과 글자를 입력하는 줄이 보이면 잘 된 겁니다.
처음 켜면 질문이 몇 개 나옵니다. 영어일 수 있습니다 — 놀라지 마세요.
대부분 화살표 키(↑↓)로 고르고 Enter로 답합니다. 마우스가 아니라 키보드를 씁니다.

· 화면 색을 고르라는 질문 → 아무거나 고르고 Enter. 나중에 바꿀 수 있습니다.
· 이 폴더를 믿어도 되냐고 묻는 질문 (trust · yes 같은 단어가 보입니다) → 반드시 "예"에 해당하는 쪽을 고르세요. 여기서 "아니오"를 고르면 진행이 안 됩니다.
· 로그인하라는 질문이 또 나오면 → 4단계에서 하신 그 계정으로 하시면 됩니다.

질문이 다 지나가면 인사말이 나옵니다. 모르는 질문이 나오면 그 화면을 사진 찍어 참가방에 올려 주세요. 바로 답해 드립니다.
선택 상자에 AI가 보이지 않으면, 그 화면을 사진으로 남겨 참가방에 올려 주세요.
인사말이 보이면 맥 준비 끝! 아무것도 입력하지 않으셔도 됩니다. 이 화면은 사진으로 찍어두세요 — 마지막에 참가방에 올릴 인증 사진 두 장 중 하나입니다.

YouTube 채널과 전화번호 인증 준비

맞춤 썸네일 사용에 필요한 기능을 활성화하려면 채널 전화번호 인증을 미리 마쳐야 합니다.

영상을 올릴 내 채널이 있어야 합니다. 할 일은 두 가지 — 채널 만들기와 전화번호 인증입니다.

① 채널 만들기 — 이미 채널이 있으면 건너뛰세요

  1. 브라우저에서 youtube.com에 들어가 오른쪽 위 동그란 프로필 사진을 누릅니다.
  2. 메뉴에 [내 채널]이 보이면 이미 채널이 있는 것입니다 — ②로 바로 가세요.
  3. [채널 만들기]가 보이면 그걸 누르고, 이름은 아무거나 적고 넘어가세요. 나중에 바꿀 수 있습니다.

② 전화번호 인증 — 주소 하나로 바로 갑니다

  1. 브라우저 주소창에 아래를 붙여넣고 Enter를 누르세요. 메뉴를 타고 들어갈 필요가 없습니다.
  2. 휴대폰 번호를 넣고 문자로 받기를 고른 뒤, 문자로 온 6자리 숫자를 넣으면 끝입니다.
youtube.com/verify
"이미 인증됨"이라고 나오면 예전에 해두신 것이니 그냥 넘어가시면 됩니다.
전화번호 인증은 꼭 해주세요. 이게 없으면 나중에 썸네일이 자동으로 안 붙습니다. 1분이면 끝나고, 지금 해두는 편이 훨씬 편합니다.

공개 채널 분석용 API 키 준비

이 키는 2일차에 참고 채널의 공개 통계를 읽는 데만 사용합니다.
내 채널에 접근하거나 영상을 대신 올리는 권한이 아닙니다. 영상 게시와 예약은 YouTube Studio에서 직접 진행합니다.

시작 전에 세 가지를 확인하세요.
· 전부 무료입니다. 카드 등록도 없습니다.
· 내 구글 계정 안에서만 만들어지는 것이고, 남에게 공개되지 않습니다.
· 키 문자열은 비밀번호처럼 취급하고 사진이나 채팅에 공개하지 않습니다.
이 단계는 Day 0 완료와 인증에 필요한 필수 단계입니다.
프로젝트 만들기 → API 사용 → 키 생성·제한의 세 화면으로 진행되며 약 5~10분이 걸립니다. 막히면 키 문자열을 가리고 현재 화면만 참가방에 올리세요.

손이 제일 적게 가는 길 — 옆에 있는 AI에게 시키세요

6단계에서 열어둔 Orca의 AI가 옆에 있습니다. 아래 글을 붙여넣으면 한 화면에 하나씩 알려주고, 내가 "됐어"라고 할 때까지 기다려 줍니다. 화면이 안내와 다르면 보이는 대로 말하면 거기에 맞춰 다시 알려줍니다.

공개 유튜브 채널 분석에 쓸 API 키를 만들려고 해. 나는 컴퓨터를 잘 몰라.
한 번에 화면 하나씩만 알려주고, 내가 "됐어"라고 하면 다음 화면을 알려줘.
버튼 이름은 화면에 보이는 글자 그대로 말해줘.

만들 것: console.cloud.google.com 에서
1) 새 프로젝트 (이름: 플리공장)
2) YouTube Data API v3 사용 설정
3) API 및 서비스 → 사용자 인증 정보에서 API 키 만들기 → YouTube Data API v3로 제한 → 복사
4) 키 문자열을 ~/플리공장/API키.txt에 저장

내가 지금 보는 화면을 설명하면 거기에 맞춰서 알려줘.
중간에 내가 뭘 잘못 눌렀는지 물어보면 되돌리는 법도 알려줘.

직접 진행하기 — 세 단계입니다

먼저 브라우저에서 아래 주소를 열고, 유튜브 채널이 있는 구글 계정으로 로그인해 주세요.

console.cloud.google.com

화면 1 — Google Cloud 프로젝트 만들기

  • 화면 맨 위 왼쪽, Google Cloud 글자 바로 옆에 둥근 알약 모양의 칸이 있습니다. 그게 프로젝트를 고르는 칸입니다. 누르세요.
  • 리소스 선택 창이 뜹니다. 오른쪽 위의 파란 글씨 [새 프로젝트]를 누르세요.
  • 이름 칸에 플리공장이라고 적고 [만들기].
  • 잠시 뒤 만들어집니다. 맨 위 알약 칸에 "플리공장"이 보이는지 확인하세요.
✅ 맨 위에 "플리공장"이 보이면 성공입니다. 이후 설정은 이 프로젝트에 저장됩니다.
만든 뒤 맨 위 칸에 다른 이름이 보이면 그 칸을 다시 눌러 목록에서 플리공장을 선택하세요. 프로젝트가 다르면 이후 설정도 다른 곳에 저장됩니다.

화면 2 — YouTube Data API v3 사용 설정

  • 화면 맨 위 가운데 검색창에 아래를 붙여넣고 Enter.
  • 검색 결과에서 YouTube Data API v3 를 누르면 소개 화면이 나옵니다.
  • 파란 [사용] 버튼을 누르세요. (영어면 ENABLE)
YouTube Data API v3
✅ 버튼이 [사용] → [관리] 로 바뀌면 성공.

화면 3 — 채널 분석용 API 키 만들기

  • ≡ → API 및 서비스 → 사용자 인증 정보 로 갑니다.
  • [+ 사용자 인증 정보 만들기] → 이번엔 [API 키] (위 사진의 맨 윗줄)를 누르세요.
  • 바로 만들어집니다. 나온 긴 글자를 복사해 두세요. (AIza 로 시작합니다)
  • [키 제한]을 누릅니다. 이 로컬 실습에서는 애플리케이션 제한은 없음으로 두고, API 제한 → 키 제한 → YouTube Data API v3만 선택해 저장합니다.
✅ 복사했으면 성공. 다음 단계에서 이 글자를 파일로 저장합니다.
API 키는 목록에서 다시 확인할 수 있습니다. 다만 키 문자열이 보이는 화면을 촬영하거나 채팅방에 공유하지 마세요.
API 키는 공개 채널의 조회수·길이·발행 요일을 읽는 번호표입니다. 2일차의 「이 채널 분석해줘」에만 사용하며, 내 채널의 영상·설정에는 접근하지 않습니다.

마지막 — API 키를 제자리에 저장하기

  1. 복사해둔 API 키를 파일 하나에 저장합니다.
    1. ⌘+스페이스를 누르고 텍스트 편집이라고 입력해 여세요. 새 문서가 안 열리면 [파일] → [새로 만들기]
    2. 그 창 안을 한 번 누르고 ⌘+V로 붙여넣습니다. AIza로 시작하는 긴 글자가 보이면 맞습니다
    3. 붙여넣은 다음 위 메뉴에서 [포맷] → [일반 텍스트로 만들기]를 한 번 눌러 주세요. 글씨 모양이 조금 바뀌면 된 겁니다.
      안 누르셔도 공장이 알아서 찾아냅니다. 다만 눌러 두면 파일이 API키.txt로 깔끔하게 저장돼서 나중에 눈으로 찾기 쉽습니다. 서식이 달라도 공장이 앞뒤 공백을 제거해 읽습니다
    4. [파일] → [저장]을 누르면 저장 창이 열립니다. 이름 칸에 API키라고 적으세요
    5. 그 창이 떠 있는 상태에서 ⌘+Shift+G를 함께 누르면 주소를 적는 작은 칸이 나옵니다. 아래 버튼으로 복사한 주소를 ⌘+V로 붙여넣고 Enter, 그다음 [저장]입니다.
      폴더를 찾아 들어갈 필요는 없습니다. 저장 창 왼쪽 목록에 「플리공장」이 보이지 않아도 아래 주소를 입력하면 바로 이동합니다. 
      ~/플리공장
    6. 저장한 뒤 창 맨 위에 「API키」라고 뜨면 된 겁니다. 이제 닫으셔도 됩니다

붙여넣고 [포맷] → [일반 텍스트로 만들기], 그다음 [파일] → [저장]입니다. 이름은 API키, 위치는 위에서 복사한 주소면 끝입니다.

Suno 계정 준비

인증 메일이 스팸함으로 들어가는 경우가 있으므로 수노 가입을 미리 완료해 두세요.

수노는 노래를 만들어 주는 사이트입니다. 며칠 뒤 내 곡을 만들 때 쓰는데, 가입만 오늘 해두면 그날 바로 시작할 수 있습니다.

  1. 브라우저에서 suno.com에 들어가 [Sign Up]으로 가입해 주세요. 구글 계정으로 가입하면 비밀번호를 새로 만들지 않아도 됩니다.
  2. 무료로 시작할 수 있습니다. 지금 결제하지 않으셔도 됩니다.
  3. 가입만 확인하고 창을 닫으세요. 곡은 나중에 만듭니다.
오늘은 무료로 가입만 하시면 됩니다. 무료 계정은 하루에 만들 수 있는 곡 수가 정해져 있습니다. 3일차까지는 무료로 충분합니다. 곡을 한두 개만 만드는 날이기 때문입니다.
다만 3일차와 5일차에는 곡을 여러 번 만들어 보게 되고, 무료로 만든 곡은 수노 규정상 돈 버는 용도로 쓰는 데 제한이 있습니다. 그래서 그때 유료로 올리는 분이 대부분입니다.
오늘은 결제하지 마세요. 얼마인지는 수노 화면에 그때그때 표시되는 값을 보시면 됩니다. 곡이 막히는 날 참가방에 올려 주시면 같이 보겠습니다. 미리 알려드리는 이유는, 그날 갑자기 알게 되는 게 제일 당황스럽기 때문입니다.
