이제 진짜
공장을 켜볼게요

오늘은 받으신 파일을 공장에 넣고, 내 유튜브를 연결하고, 샘플 영상 한 편을 비공개로 올려봅니다.
약 40~70분이고, 중간에 쉬었다 이어서 해도 괜찮습니다.

먼저, 내가 쓰는 AI를 골라볼게요

지난번 설치할 때 고른 AI와 같은 것을 눌러 주세요. 누른 뒤에는 그 AI에 필요한 안내만 보입니다.

위의 두 버튼 중 하나를 누르면 다음 안내가 열립니다.

0

오늘 할 일을 먼저 볼게요

지난번 첫 번째 안내서(시작 전 환경 세팅)가 끝나 있어야 오늘 진행이 됩니다. 아래 세 가지를 먼저 확인해 주세요.

이 세 가지가 되어 있으면 오늘 시작할 수 있습니다.
□ 파워셸에서 설치 결과 표를 본 적이 있습니다.
□ Orca에서 플리공장 폴더가 열립니다.
□ Orca 안에서 내 AI가 열리고 인사말이 보입니다.
아직 안 되어 있다면 오늘 것을 먼저 하지 마시고, 첫 번째 안내서부터 끝내 주세요. 그게 훨씬 빠릅니다.

오늘 하는 일 여섯 가지

  1. 받으신 파일(셋팅코드)을 공장에 넣습니다.
  2. 공장이 잘 준비됐는지 AI에게 확인시킵니다.
  3. 유튜브 채널을 만들고 전화번호 인증을 합니다.
  4. 내 유튜브를 공장에 연결합니다. (오늘 가장 오래 걸리는 부분입니다)
  5. 수노에 가입해 둡니다.
  6. 샘플곡으로 첫 영상을 만들어 비공개로 올려봅니다.

옆에 두면 좋은 것

  • 메일이나 링크로 받은 셋팅코드 zip 파일.
  • 유튜브에 쓸 구글 계정(이메일·비밀번호).
  • 인증번호를 받을 휴대폰.
용어는 외우지 않으셔도 됩니다. 이 안내서에 보이는 버튼만 차례대로 눌러 주세요.
1

받으신 파일을 공장에 넣을게요

압축을 직접 푸실 필요가 없습니다. 파일을 다운로드만 해두고, 지난번에 쓰셨던 설치 한 줄을 한 번 더 실행하면 컴퓨터가 알아서 공장 안에 넣어 줍니다.

  1. 메일이나 링크에서 셋팅코드 zip 파일을 다운로드해 주세요. 다운로드 폴더나 바탕화면에 그대로 두시면 됩니다.
  2. 압축을 풀지 마세요. 파일 이름도 바꾸지 마세요. 이름에 셋팅코드라는 글자가 들어 있어야 컴퓨터가 찾아냅니다.
  3. Orca가 열려 있으면 지금은 닫아 주세요. 파일을 넣은 뒤에 다시 엽니다.
  4. 키보드 왼쪽 아래 윈도우 모양 키를 누르고 powershell을 영어로 입력한 뒤, Windows PowerShell을 눌러 주세요.
  5. 아래 상자를 복사해 파워셸 창 안을 한 번 누르고 마우스 오른쪽 버튼으로 붙여넣은 다음 Enter를 눌러 주세요.

클로드 사용자

$env:PLI_AI='claude'; irm https://raw.githubusercontent.com/KIMYOUNGIL21/r-64fe20c017/main/pli/setup.ps1 | iex

코덱스 사용자

$env:PLI_AI='codex'; irm https://raw.githubusercontent.com/KIMYOUNGIL21/r-64fe20c017/main/pli/setup.ps1 | iex
지난번과 똑같은 한 줄입니다. 이미 깔린 것은 전부 건너뛰기 때문에 이번에는 훨씬 빨리 끝납니다. 여러 번 실행해도 안전합니다.
이렇게 나오면 성공입니다.
마지막 표의 셋팅코드 줄에 방금 넣음 또는 있음이라고 적혀 있으면 됩니다.
셋팅코드 줄에 "나중에"라고 나오면 컴퓨터가 zip 파일을 못 찾은 것입니다. ① 파일을 정말 다운로드했는지 ② 파일 이름에 셋팅코드가 들어 있는지 ③ 다운로드 폴더나 바탕화면에 있는지를 확인하고, 설치 한 줄을 한 번 더 실행해 주세요.
"확인 필요"라고 나와도 괜찮습니다. 다음 단계에서 AI가 무엇이 빠졌는지 찾아서 채워 줍니다. 일단 다음으로 넘어가 주세요.
2

공장이 잘 준비됐는지 AI에게 확인시킬게요

설치는 앞에서 끝났습니다. 여기서는 AI에게 제대로 됐는지 확인만 시킵니다. 보통 1~3분이면 됩니다.

  1. 바탕화면 또는 시작 메뉴에서 Orca를 열어 주세요. 고래 모양 아이콘입니다.
  2. 지난번에 등록해 둔 플리공장 폴더를 눌러 주세요. (목록에 없으면 Add Project → 폴더 찾아보기 → 내 PC → 로컬 디스크 C → 플리공장)
  3. 터미널 또는 새 터미널 버튼을 눌러 아래쪽에 검은 창을 띄워 주세요.
  4. 검은 창 위쪽의 Agent 또는 선택 상자를 누르고 Claude Code를 골라 주세요.
  5. 검은 창 위쪽의 Agent 또는 선택 상자를 누르고 Codex를 골라 주세요.
  6. AI 인사말이 보이면, 아래 글을 전체 복사해서 그 창에 마우스 오른쪽 버튼으로 붙여넣고 Enter를 눌러 주세요.
지금부터 너는 내 유튜브 플레이리스트 영상 공장의 기술자야. 나는 코딩을 전혀 못 하니까, 작업은 전부 네가 하고 나한테는 결과와 다음 행동만 한국어로 알려줘.

설치는 파워셸에서 이미 끝냈어. 네가 할 일은 확인이야.
1. 이 폴더의 AGENTS.md를 읽고, 없으면 CLAUDE.md를 처음부터 끝까지 읽어줘. 앞으로 그 지침을 따라줘.
2. 자가진단을 돌려서 한글 표로 보여줘: ffmpeg · Python · Node.js · Google Chrome · 유튜브용 파이썬 패키지 2개(google-api-python-client, google-auth-oauthlib) · Playwright MCP 등록 상태 · 재료/완성/기록 폴더 · 셋팅코드 파일들(공장.py, 업로더.py, 분석기.py, 설정.json) · 재료 폴더의 샘플 4종.
3. 빠지거나 실패한 것이 있으면 그것만 네가 직접 설치하거나 만들어서 채워줘. 다 됐으면 아무것도 새로 설치하지 마.
4. 전부 통과하면 마지막 줄에 크게 ✅ 공장 준비 완료 라고 쓰고, 시작하세요.md 내용을 세 줄로 요약해서 "앞으로 이렇게 쓰시면 됩니다"라고 알려줘.
5. Playwright MCP가 목록에 안 보이면, 지금 터미널을 닫고 Orca에서 새 터미널을 열어 같은 AI를 다시 선택하라고 알려줘. (등록은 돼 있어도 새 터미널에서만 보여.)
6. 하나라도 실패하면 완료라고 말하지 말고, 코딩 처음 하는 사람 기준으로 다음 행동 하나만 알려줘.
AI 화면에 ✅ 공장 준비 완료가 보이면 통과입니다. 이 화면은 나중에 인증 사진으로 쓰니 그대로 두세요.
AI가 새 터미널을 열라고 하면 그대로 해주세요. 아래쪽 검은 창을 닫고 새 터미널을 다시 눌러 같은 AI를 고르면 됩니다. 나중에 수노를 열 때 필요한 준비입니다.
빨간 글씨가 나와도 놀라지 마세요. AI가 원인을 찾아 스스로 고치는 경우가 많습니다. 두세 번 시도해도 같은 자리에서 멈추면 그 화면을 사진으로 찍어 참가방에 올려 주세요.
3

유튜브 채널을 만들고 전화번호 인증까지 해둘게요

영상을 올릴 내 채널이 있어야 합니다. 이미 채널이 있으면 전화번호 인증만 확인하고 넘어가세요.

  1. 브라우저에서 youtube.com에 들어가 오른쪽 위 프로필을 누르고 [채널 만들기]를 눌러 주세요.
  2. 채널 이름은 나중에 바꿀 수 있습니다. 지금은 아무거나 적고 넘어가도 됩니다.
  3. 이어서 studio.youtube.com에 들어가 주세요. 유튜브 스튜디오입니다.
  4. 왼쪽 아래 [설정] → [채널] → [기능 사용 자격요건] → [전화번호 인증]을 눌러 문자로 온 번호를 넣어 주세요.
전화번호 인증은 꼭 해주세요. 이게 없으면 나중에 썸네일이 자동으로 안 붙습니다. 1분이면 끝나고, 지금 해두는 편이 훨씬 편합니다.
다음 단계에서 쓸 계정을 기억해 두세요. 방금 채널을 만든 바로 그 구글 계정으로 유튜브를 연결해야 합니다. 계정이 여러 개면 여기서 한 번 정해두는 게 좋습니다.
내 채널 화면이 보이면 됩니다.
4

유튜브에 자동으로 올릴 수 있게 연결할게요

이 챌린지는 영상 업로드와 예약 발행까지 자동입니다. 그러려면 내 유튜브를 공장에 한 번 연결해 둬야 합니다. 무료이고, 처음 한 번만 하면 됩니다.

  1. Orca의 AI 입력창에 아래 글을 붙여넣고 Enter를 눌러 주세요.
  2. AI가 브라우저에서 눌러야 할 버튼을 한 화면에 하나씩 알려줍니다. 서두르지 말고 그대로만 따라가면 됩니다.
  3. 중간에 "확인되지 않은 앱" 경고가 나오면 [고급] → [이동]을 눌러 주세요. 내가 방금 만든 내 앱이라 안전합니다.
  4. 마지막에 ✅ 유튜브 연결 완료가 보이면 끝입니다.
유튜브 연결해줘. 분석기용 API 키도 같은 화면에서 같이 만들어서 설정에 저장해줘.
여기가 오늘 가장 오래 걸리는 부분입니다 (15~25분). 구글 사이트에서 클릭할 게 많습니다. 어렵게 느껴지는 게 정상이니 조급해하지 마세요. 막히면 그 화면을 사진으로 남겨 참가방에 올려 주세요 — 당일 안에 같이 풀어드립니다.

이런 순서로 지나갑니다 (미리 알고 계시면 덜 놀랍니다)

  1. 구글 클라우드라는 사이트에 들어가 내 작업 공간(프로젝트)을 하나 만듭니다. 이름은 아무거나 괜찮습니다.
  2. YouTube Data API v3라는 기능을 찾아 [사용]을 누릅니다.
  3. 동의 화면에서 외부를 고르고 앱 이름과 이메일만 채웁니다. 그리고 테스트 사용자에 내 이메일을 추가합니다.
  4. 데스크톱 앱이라는 열쇠를 만들고 [JSON 다운로드]를 누릅니다. 받은 파일은 AI가 알아서 공장에 옮겨 줍니다 — 직접 옮기지 않으셔도 됩니다.
  5. 브라우저에서 내 채널이 있는 구글 계정을 고르고 [허용]을 누릅니다.
  6. 같은 화면에서 API 키도 하나 만들어 AI가 설정에 저장합니다.
왜 API 키도 같이 만드나요? 둘 다 같은 구글 화면에서 만듭니다. 지금 한 번에 해두면 나중에 이 복잡한 화면에 다시 들어올 일이 없습니다. 며칠 뒤 "이 채널 분석해줘"를 할 때 바로 됩니다.
며칠 뒤 "연결이 풀렸다"고 나와도 고장이 아닙니다. 구글 규칙상 7일마다 한 번 풀립니다. 잘못하신 게 아닙니다. 그때는 AI에게 "유튜브 연결해줘"라고 다시 말하고 [허용]만 누르면 됩니다. 만들어 둔 영상·재료·설정은 그대로 있습니다. 구글 사이트에 다시 들어갈 필요도 없습니다.
올릴 게 있는 날 미리 확인하고 싶으면 AI에게 "유튜브 연결 살아 있어?"라고 물어보세요. 며칠 남았는지 알려줍니다.
5

수노에 가입해둘게요

수노는 노래를 만들어 주는 사이트입니다. 내 곡을 만들 때 쓰는데, 가입만 오늘 해두면 그날 바로 시작할 수 있습니다.

  1. 브라우저에서 suno.com에 들어가 [Sign Up]으로 가입해 주세요. 구글 계정으로 가입하면 가장 간단합니다.
  2. 무료로 시작할 수 있습니다. 지금 결제하지 않으셔도 됩니다.
  3. 가입만 확인하고 창을 닫으세요. 곡은 나중에 만듭니다.
무료 플랜은 하루에 만들 수 있는 곡 수에 한도가 있습니다. 마음에 드는 곡이 잘 안 나오면 그날 유료로 올리는 분도 있는데, 지금 정하실 필요는 없습니다.
비밀번호와 인증번호는 항상 본인이 직접 입력해 주세요. AI에게 알려주지 않으셔도 되고, 알려주시면 안 됩니다.
6

샘플로 첫 영상을 한 번 올려볼게요

이제 확인만 하지 말고, 공장에 들어 있는 샘플곡으로 영상 하나를 만들어 내 유튜브에 올려보겠습니다. 처음에는 비공개로 올리니 다른 사람에게 보이지 않습니다.

  1. 앞에서 새 터미널을 열라는 안내를 받았다면, 지금 검은 창을 닫고 Orca에서 새 터미널을 열어 같은 AI를 다시 선택해 주세요. (안내가 없었으면 그냥 넘어가세요.)
  2. Orca의 AI 입력창에 아래 글을 복사해 붙여넣고 Enter를 눌러 주세요.
  3. 유튜브 연결은 앞 단계에서 이미 끝났으니, 바로 영상 만들기부터 진행됩니다.
  4. 샘플 영상과 제목이 준비되면 AI가 비공개로 올릴까요라고 물어봅니다. 확인한 뒤 괜찮으면 응, 비공개로 올려줘라고 답해 주세요.
  5. 마지막에 유튜브 영상 링크가 나오면, 내 채널에 첫 연습 영상이 올라간 겁니다.
샘플로 연습 업로드해줘
영상을 만드는 동안 시간이 걸립니다. 화면이 한동안 조용해도 정상이니 창을 닫지 말고 기다려 주세요.
업로드가 끝나면 유튜브 스튜디오에서 [변경된 콘텐츠]의 AI 사용 표시를 "예"로 확인해 주세요. 앞으로 올릴 때마다 하는 습관입니다.
비공개 영상이 유튜브 스튜디오에 보이면 오늘 목표를 다 하신 겁니다.

중간에 멈춰도 괜찮아요

  • 어려운 말이 보이면 혼자 해결하려 애쓰지 않아도 됩니다. 멈춘 화면을 사진으로 한 장 남겨 주세요.
  • 몇 번째 단계에서 멈췄는지만 함께 적어 참가방에 올려 주세요. 당일 안에 같이 풀어드립니다.
  • 설치와 관련된 문제는 대부분 설치 한 줄을 한 번 더 실행하면 해결됩니다. 여러 번 해도 안전합니다.
  • AI가 엉뚱한 말을 하면 "다시 처음부터 한 단계씩 알려줘"라고 말해 보세요. 그래도 안 되면 검은 창을 닫고 새 터미널에서 다시 시작하면 됩니다.
  • 사진을 보낼 일이 있다면 비밀번호, 인증번호, 카드번호는 보이지 않게 가려 주세요.
  • 답답해도 프로그램을 지우거나 다른 설치를 하기보다는, 잠시 그대로 두는 편이 좋습니다.
